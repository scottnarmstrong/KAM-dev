## Blueprint defects / deviations
1. Deviation (not a defect): the blueprint says |β_j| ≤ (1+m)^{1/4} j^{1/2}; Lean proves the weaker, simpler
   `|β_j| ≤ (1+m) j` (B = 1+m, ν = 1) for both β = λ^{∓1/2}, since the feature lemma only needs *some* B, ν ≥ 0
   (all that matters is summability of j^{ν+k-p} e^{-(a-a')j}). The blueprint's constants are true but not used.
2. Presentational: blueprint writes φ_j^{(k)} = √(2/π) j^k sin^{(k)}(jx); Lean writes sin^{(k)}(t) as
   sin(t + kπ/2) (same function; derivative identity is `hasDerivAt_sineModeIter`).
3. Statement shape: Lean (i)/(ii) of sine-completeness take `MemLp f 2 (volume.restrict (Ioo 0 π))` for "f ∈ L²(0,π)";
   (ii) keeps the blueprint's hypothesis that f is both L² and continuous on [0,π]. The hypotheses
   `∫ x in 0..π, f x * sineMode l x = 0` are exactly the blueprint's `∫₀^π f φ_l = 0`.
4. In (iii) of recon-analytic the blueprint says "for every x₀ and k" at (s₀,x₀) — as proved. The `S = ℝⁿ` form is
   the `S`-generic statement with `S := Fin n → ℝ`.
   No missing Mathlib names: blueprint's `lp.inner_eq_tsum` is `lp.inner_eq_tsum`/`lp.hasSum_inner` in
   `Mathlib.Analysis.InnerProductSpace.l2Space`; `ContinuousLinearMap.analyticAt_bilinear` exists as cited.
   Blueprint step `stepW:w1:basis` cites the Fourier-basis injectivity; Lean uses Parseval
   (`tsum_sq_fourierCoeffOn`) instead, which avoids building an `Lp` element for the odd extension.
