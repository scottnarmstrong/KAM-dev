## Target 1: the scalar solve, and the norm the radius lives in

**The norm.** `CertModel.EnclosesL1 n ρ m f` (for `m = ⟨deg, P, rad⟩`) states the bound below for the torus
coefficients `R_k = f̂_k − (2π)^deg P̂_k` of the remainder on the real torus. This is the weighted ℓ¹ (Wiener-algebra)
norm at strip width `ρ`, the norm of `KAM.cohomological_l1`.

```
Σ_k |R_k| e^{2πρ|k|₁} ≤ (2π)^deg rad
```

The input and output radii of the solve both live in this norm. The certifier's own `CertModel.Encloses` is a sup
norm, and two bridges connect the two:
- **`EnclosesL1.encloses` (ℓ¹ ⇒ sup).** If `f` is the Fourier series of its coefficients on `T_ρ`, the same model
  encloses `f` in sup on `T_ρ`.
  - Every cohomological solution qualifies (`cohSolve_encloses`), and so does every holomorphic periodic `f` with
    summable coefficients (SHARP-L9's bridge).
  - The output therefore feeds the existing sup arithmetic directly: `CertModel.mul`, `add`, `toDeg`, `average`,
    `supBound`.
- **`Encloses.toL1` (sup ⇒ ℓ¹).** A sup enclosure on `T_ρ` of a holomorphic `1`-periodic `f` is an ℓ¹ enclosure at
  `ρ − δ₁` by the same polynomial, with radius `C·rad` for any `C ≥ coth(πδ₁)^n`.
  - `cothPowUp n δ₁ = (1 + 1/(3.14 δ₁))^n` is a rational `C`.
  - **What pays.** Only the remainder pays this factor; the polynomial part is carried exactly. This is how the
    certifier's sup models (the invariance error `E`, frame products) enter the solve.

**The solve** (`CertModel.cohSolve n box Γ W m`).
- **Degree.** The output model has degree `deg − 1`, which absorbs the `2π` of `2πi k·ω`.
- **Terms.** For each term `(k, c_k)`:
  - **Dropped** if its key is zero: the solve has no zero mode, so no zero-mean premise is needed.
  - **Divided** if the box lower bound `L_k = |D_k| − R_k` of `|k·ω|` is positive (C2's `boxLb`). Here
    `D_k = k·(box centre)` and `R_k = Σ|k_i| r_i`. The new centre is `ofRatUp(1/D_k) · (−i c_k)`; `1/D_k` is an
    exact rational, so this is one backend product and no division in the backend.
- **Per-term error** (`solveItem_err`). For every `ω` in the box,
  `e_k = |c_k| (R_k/(L_k|D_k|) + width(1/D_k)) + rounding` bounds `|c_k/(i k·ω) − centre_k|`. It comes from
  `|1/x − 1/D| = |D − x|/(|x||D|)`.
- **Output radius:** `errRadius W (items) + 2·piUpQ·Γ · rad`, with:
  - `errRadius W = Σ_k e_k w^{|k|₁}` at the output weight `W`, which bounds the ℓ¹ norm at width `W.rho`
    (`sum_err_le_errRadius`);
  - `Γ ≥ Γ_∞(ω, ρ − W.rho)` (SHARP-L9's `smallDivisorSup`), which carries the remainder through
    `KAM.summableWeighted_solve_sup`.
- **Side condition** (`solveCheck`): every term is divided or has a zero key.

```
theorem CertModel.EnclosesL1.cohSolve {box : FreqBox} {ω : Fin n → ℝ}
    (hbox : FreqEncloses n box ω) {γ τ : ℝ} (hω : IsDiophantine γ τ ω) (hγ : 0 < γ)
    (hτ : 0 ≤ τ) {W : CertWeight} {sw Nw : ℕ} (hW : checkWeight W sw Nw = true) {ρ : ℝ}
    (hρ : (W.rho : ℝ) < ρ) {Γ : ℚ} (hΓ : smallDivisorSup ω (ρ - W.rho) ≤ Γ)
    {m : CertModel α} (hchk : solveCheck n box m.poly = true) {g : (Fin n → ℂ) → ℂ}
    (hg : CertModel.EnclosesL1 n ρ m g) :
    CertModel.EnclosesL1 n W.rho (CertModel.cohSolve n box Γ W m) (cohSolution ω g)
```

- **Which `g`.** `g` is any function enclosed by the model in ℓ¹; no holomorphy is needed for the coefficient
  statement.
- **Why `IsDiophantine`.** It makes the `⨆` defining `Γ_∞` a true supremum (bounded above) and gives the
  summability. `Γ` itself is certified by `supBound_sound` (target 3).
- **The proof.** `𝓡g` has coefficients `solve ω ĝ` (L9's `torusCoeff_cohSolution_l1`), so its remainder over the
  solved model is
  `(2π)^{deg−1} Σ_t [k_t = k](exact_t − centre_t) + solve ω R`.
  - The first part is a finite term list (`summableWeighted_list`), bounded term by term by `e_t`.
  - The second is bounded by L9's ℓ¹ estimate.
  - The identity is `solve_const_mul_coeff`, `coeff_itemsPoly_solveItems` and `solve_add`.

## Target 2: vectors and matrices

- **`cohSolve_pi`** (the step-0 `ξᴺ = 𝓡 ηᴺ`). For componentwise models `ms : Fin p → CertModel α` with
  `CertModel.EnclosesL1 n ρ (ms l) (g · l)`, each solved component encloses `cohSolutionPi ω g · l` in ℓ¹ and in sup.
- **`cohSolve_mat`** (`Ω_K`-type solves). The same entrywise, for `ms : Fin p → Fin q → CertModel α`. This is the
  certifier's matrix representation: take `ms i j = modelMatrixEntry M i j`.
- **`norm_cohSolutionMat_le_rowSum`.** On `T_{W.rho}`, `‖cohSolutionMat ω g θ‖ ≤ B` in the operator norm when every
  row sum of the solved entries' certified `supBound` is `≤ B` (`KAM.norm_le_iff_forall_rowSum`).

## Target 4: design note (step-0 objects and kernel cost)

**What each object needs** (the measured step 0, L6, with this core plus the existing model arithmetic).

| object | how it becomes a model | what this package supplies |
|---|---|---|
| `ηᴺ`, `ηᴸ` (frame transposes times `E`) | `CertModel.mul` of the frame models (`N`, `L` from `dkModels`/`frameNModels`, sup on `T_ρ`) with the rows of `E`, then `add`/`trim` | – (existing sup arithmetic) |
| `uᴺ = 𝓡 ηᴺ` | `Encloses.toL1` at `ρ − δ₁` (only the remainder pays `cothPowUp`), then `cohSolve_pi` | the solve, ℓ¹ and sup outputs |
| `⟨T uᴺ⟩` | `mul` of the `T` model with `uᴺ` (sup, from `cohSolve_encloses`), then `Encloses.average` (zero coefficient ± radius) | sup output of the solve |
| `ξᴸ = 𝓡(ηᴸ − T uᴺ − …)` | `toDeg` to align degrees (the solve lowers the degree by 1), `add`, `toL1`, then a second `cohSolve_pi` | the second solve |
| `ΔK₀ = L ξᴸ + N ξᴺ` | `mul`/`add` of frame and solved models | – |
| `∂_ωξ` | no derivative of a remainder is needed: `∂_ω 𝓡g = g − ⟨g⟩` (`fderiv_cohSolution`), so `∂_ωξ` is the right-hand side's model | – |
| `Ω_K` (and `Ω_K`-type matrix solves) | entrywise products; solves by `cohSolve_mat`; operator norm by `norm_cohSolutionMat_le_rowSum` | matrix solve and norm |
| `E_sym`, `E_red` | products and sums of `DK`, frame and solved models (sup arithmetic; `ofDeriv` for exact polynomial derivatives) | – |

So every step-0 object is a finite composition of the existing sup-model operations and the two certified solves.
- **Twisted objects.** The only twisted objects are `uᴺ` and `ξᴸ`, solved here.
- **What remains.** The wiring (`Step0/Objects.lean`, `Step0/Check.lean` of C5) is still to do. It needs the L6
  statement from SHARP-PLUS: which object goes into which `CertData` field.

**Kernel cost on the lunar data** (low precision: a few significant digits suffice).
- **The solve.** One pass over the model's terms costs about 20 exact rational operations per term: the box dot
  product, one rational inverse, the error bound, two backend products, and the weighted error.
  - The step-0 right-hand sides have about 10⁴ terms (§2.7), so each solve is about 2·10⁵ small-rational
    operations: seconds.
  - Precision is not an issue: the box error is `R_k/|D_k| ≈ |k|·r/|k·ω|`, about 10⁻⁸ relative with C2's lunar boxes
    (`r ≈ 10⁻¹²`, `|k| ≤ 100`, `|k·ω| ≥ 10⁻²`).
  - Coefficients can be trimmed first (`CertModel.trim`) to about 2⁻²⁰ relative; the dropped mass goes into the
    radius.
- **The products.** About 20 products, frame (≤ 10³ terms) × `E` (about 10⁴), dominate as estimated in §2.7: about
  0.1–1 CPU-h per torus at `L = 88` and 0.01–0.1 at `L ≈ 33`, rounded to about 60 bits.
- **`Γ_∞` at the lunar `δ₀ = 0.0024`.** The box checker `SupData.check` needs `N ≈ 376`, i.e. about 2.8·10⁵ modes
  with rational powers `E₁^{|k|}`. That is too heavy.
  - **The route instead.** SHARP-L9's fibered theorem `KAM.smallDivisorSup_snoc_le` needs 752 entries at δ₀. A
    rational wrapper (like C2's `fiberCheck`) is about 100 lines and is the next item.
- **The conversion factor.** `cothPowUp 2 (δ₀/2) ≈ 7·10⁴` multiplies only the remainder radius of `E` (about 10⁻⁸⁰
  relative on R1), so it is harmless.

## Uncertainties

- **Input norm.** The solve consumes ℓ¹ enclosures. The certifier's `E` comes as a sup model, so the route is
  `Encloses.toL1`, which needs `E` holomorphic and `1`-periodic on `T_ρ` (true for the invariance error of an
  analytic torus) and spends `δ₁` of strip width.
  - **ℓ¹ model products** (the same radius formulas hold in the Wiener algebra) would avoid repeated conversions, but
    are not built.
- **Γ for `τ = 1` only.** `SupData`/`supBound_sound` are stated at `τ = 1`, as C2's checkers are. The solve theorem
  itself takes any `τ`.
- **Γ_∞ cost at small δ.** See target 4: the fibered wrapper is needed for lunar `δ₀`.
