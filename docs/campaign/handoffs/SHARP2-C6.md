## Read first

1. **`KAM.lean` cannot build on `sharp-v2`, and the merge to `main` will carry that.** `Corner/SupBound.lean` and
   `Ham/TrigBound.lean` both define `KAM.CertificateSharp.expLoQ`, and the root imports both. Any file loading both fails
   with `environment already contains 'KAM.CertificateSharp.expLoQ'` (I hit it twice, in a first `Engine.lean` and in an
   axiom probe). It stays hidden because the side campaign never builds the root. `main` has neither definition yet.
   - **Fix:** rename one of them, a one-token change in a C1 or C3 file. My brief does not allow it, so I did not.
   - **What I did instead:** kept the two closures apart. Stage 2 does not need the rename (next item).
2. **The cosh pass and the frame majorants still combine, in `module` files only.** `Tests/TrigFacts.lean` and
   `Tests/FrameFacts.lean` import their checks privately and export only `HamFacts`, `FrameFacts`;
   `Tests/TrigCombined.lean` feeds both to `refinedCore_sound` (`toyCert2_cosh_torus`, kernel-checked). A non-`module` file
   importing `TrigCombined` still fails, because it follows private imports. `routeARefined` itself uses the disc pass.
   On R1 this costs nothing: disc and cosh `M₂` give the same threshold to six digits (`J2` binds, see "Thresholds").
3. **Deviation from the brief: stage 2 is sound through `iso_g1_branch_A`, not `iso_g1_v2A`.** `iso_g1_v2A` concludes with
   `max {C₂♯, c2I}`, and `C₂♯` is v1's constant at the frozen data. At the R1 threshold `C₂♯ e/(γ²ρ²) ≈ 10^0.85 ≈ 7`, above
   the ray room `(σω − s)|ω*| ≈ 1.75`, so the test would fail at the threshold it is meant to reach. The branch is the same
   audited proof and gives `c2I e/(γ²ρ²) ≈ 10⁻⁷·¹`, about 8 orders better. Stage 1 keeps the wrapper, since the max is
   harmless at 10⁻²¹.
4. **Build hazard: `.lake/build` files are hard-linked across worktrees, and Lake rewrites `.trace` in place.** A build in
   `sharp-v2` overwrote `KAM/Sharp2/RouteA/Data.trace` here (10 links). After the merge my source matched that trace, so
   Lake reported `Data` up to date on a stale olean, and `NumA.Wf.bbar` appeared not to exist.
   - **Detect:** `.olean.hash` differs from the trace's `outputs.o[0]`. Here 3 of 1065 modules: `Sharp2.RouteA.Data`,
     `Sharp2.RouteA.Frozen`, `Iso.Sharp2.RouteA.Frozen`.
   - **What I did:** replaced this worktree's 8359 linked `.trace`/`.hash` files with private copies, and deleted those 3
     traces so they rebuilt here. Other worktrees' files were not touched by that step.
   - **Disclosure:** my builds before that step wrote through the shared traces too. Another worktree could be fooled the
     same way if its source matches one of those traces. I did not audit the other worktrees.

## The soundness statements

```lean
structure EngineV2 where
  Wit : Type
  test : {n : ℕ} → {α : Type} → [CertArith α] → TorusCertificate n α → Wit → Bool
  sound : ∀ {n : ℕ} {α : Type} [CertArith α] [LawfulCertArith α] (c : TorusCertificate n α)
    (w : Wit) {ωstar : Fin n → ℝ}, FreqEncloses n c.freqBox ωstar →
    IsDiophantine (c.params.γ : ℝ) (c.params.tau : ℝ) ωstar → BaseFacts c ωstar →
    test c w = true → CertifiedTorus c ωstar

theorem checkTorusCertificateV2_sound [LawfulCertArith α] (E : EngineV2)
    {c : TorusCertificate n α} {w : E.Wit} (h : checkTorusCertificateV2 E c w = true)
    {ωstar : Fin n → ℝ} (hω : FreqEncloses n c.freqBox ωstar)
    (hdio : IsDiophantine (c.params.γ : ℝ) (c.params.tau : ℝ) ωstar) : CertifiedTorus c ωstar

theorem checkTorusCertificateV2_sharp (c : TorusCertificate n α) :
    checkTorusCertificateV2 sharpV2 c () = checkTorusCertificateSharp c := rfl

theorem frozenCore_sound [LawfulCertArith α] (c : TorusCertificate n α) (w : FrozenWit)
    {ωstar : Fin n → ℝ} (hω : FreqEncloses n c.freqBox ωstar)
    (hdio : IsDiophantine (c.params.γ : ℝ) (c.params.tau : ℝ) ωstar) (B : BaseFacts c ωstar)
    (h : frozenCore n c.params c.freqBox w = true) : CertifiedTorus c ωstar

theorem refinedCore_sound (c : TorusCertificate n α) (w : RefinedWit) {ωstar : Fin n → ℝ}
    (hω : FreqEncloses n c.freqBox ωstar)
    (hdio : IsDiophantine (c.params.γ : ℝ) (c.params.tau : ℝ) ωstar) (B : BaseFacts c ωstar)
    (hH : HamFacts c w.R) (hF : FrameFacts c w.R ωstar)
    (h : refinedCore n c.params c.freqBox w = true) : CertifiedTorus c ωstar
```

`BaseFacts`, `HamFacts`, `FrameFacts` are bounds on explicit objects with no smallness, proved by checks; `sound` is proved
per instance and is never a premise of `checkTorusCertificateV2_sound`. The engines are `routeAFrozen`, `routeARefined`, and
`routeAV2 = sharpV2.orElse (routeAFrozen.orElse routeARefined)`, where the witness names the route.

**How `Θ` was resolved.** The wrappers need `N.Θ = σω‖ω*‖` as an equality. They are applied at `σh = Θ̂/‖ω*‖ ≥ σω`, where
`Θ̂ = σω · boxNormUp box`. All numbers stay rational and independent of `ω*`, and the body is an `IG1Body` at `σh`. The price
is `sinf < σh`; the test adds `disp < (σω − s) L`, with `L` the box's lower bound of `‖ω*‖`, and `ray_lt_of_disp` recovers
`sinf < σω`.

## Deviations

1. Stage 2 through `iso_g1_branch_A` ("Read first" 3).
2. Stage 1 through `iso_g1_v2A_default`, as the orchestrator's note asked, not `iso_g1_v2A_frozen`. Its threshold `torsionXs` is
   a real number through `cohConstR`. The test checks `(1 + A) X⋆ ≤ 1` for a rational `A ≥ torsionCoef`, so `torsionXs = X⋆`
   (`torsionXs_eq`). So the test does keep a torsion comparison; it is not binding on R1.
3. `EngineV2.sound` concludes `CertifiedTorus` directly, not `∃ C₁ C₂ C₃`, because route A's refined body is not a literal
   `IG1Body`. `Admissible` and `certifiedTorus_of_ray` are the shared wiring. `BaseChecker` and `orElse` are additions.
4. The average bite is `b_s = min r_s 1` everywhere, so T2 (`ρ = 9`) runs unmodified.
5. R1 stage 2 uses prefix 3, not the design's 5: −11.33 meets the target, and prefix 5 is costly in the kernel.
6. Deliberate duplicates: `HamClaim.lean` repeats the disc half of `Ham/SplitBounds.lean` (the clash), and `boxNormUp` repeats
   `freqNormUp`, so stage 1 stays free of the Corner closure.
7. `sites` are certified for `n = 2`, `τ = 1` only, as C2's checker is; other cases take `none`, the classical constant.
