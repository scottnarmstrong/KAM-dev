## Task 1: the §0 identity (`ReducedElements`)

Definitions:
- `redMass ν μ i = ν i / √(1 + μ ν i)`;
- `reducedKeplerEnergy ν μ z i = (1/ν i + μ)|p|²/2 − ν i/|q|` (`E^red`);
- the reduced problem's mass `reducedBeta = ν/(1+μν)` and central parameter `reducedCentral = 1+μν`;
- `reducedKeplerAxis = −βM/(2E^red)`;
- `reducedDelaunayAction = β √(M a^red)`;
- `reducedEccVector` (the LRL coefficient is `1/(β²M)`).

Theorems:
- `movingHamiltonian_eq_sum_reducedKeplerEnergy`: `movingHamiltonian 1 1 ν μ z = Σ E^red_i + μ·(pair terms)`. So
  `E^red` is literally the Kepler summand.
- `reducedKeplerEnergy_eq_kepler`: `E^red = |p|²/(2β) − βM/|q|`.
- §0 at `ν' = redMass ν μ`, for `0 < ν i` and `0 < 1 + μν i`, with no energy sign needed:
  - `keplerEnergy_redMass`: `keplerEnergy ν' z i = E^red_i / s_i`;
  - `keplerAxis_redMass`: `= reducedKeplerAxis` (`reducedKeplerAxis_eq`: `= −ν/(2E^red)`);
  - `keplerAction_redMass`: `keplerAction ν' z i = reducedDelaunayAction ν μ z i`;
  - `keplerEccVector_redMass`;
  - `strongAMD_redMass`: `strongAMD ν' z = Σ Λ^red − |L|`.
- `reducedKeplerEnergy_eq_add`: `E^red = E + μ|p|²/2`.
- `keplerAction_redMass_eq_mul`: for `E < 0`, `Λ^red = Λ √(E/E^red)/s`.
- `redMass_pos`, `redMass_le`, `redMass_zero`, `one_add_mul_pos`.

## Task 2: the observable bridge (`ObservableBridge`)

```lean
def chartTube (ν : Fin n → ℝ) (z₀ : Phase (n * 2)) (r : ℝ) : Set (Phase (n + n)) :=
  {w | w ∈ chartSafe ν ∧ ‖fast w.2 - actionVector ν z₀‖ < r ∧
    chartAMD w ≤ strongAMD ν z₀ + n * r}

theorem stoppedDrift_of_approxIntegrals_obs {ν : Fin n → ℝ} {U : Set (Fin n → ℝ)}
    {z₀ : Phase (n * 2)} {δ r : ℝ} (hd : LiftData ν U z₀ δ r) {μ T d ε : ℝ}
    (G F : Fin n → Phase (n + n) → ℝ) (R O : Set (Phase (n + n)))
    (η lo hi loG hiG : Fin n → ℝ)
    (hO : IsOpen O) (hRO : R ⊆ O) (hF : ∀ i, DifferentiableOn ℝ (F i) O)
    (hGc : ∀ i, ContinuousOn (G i) (chartTube ν z₀ r))
    (hGΛ : ∀ i, ∀ w ∈ chartTube ν z₀ r,
      loG i ≤ G i w - fast w.2 i ∧ G i w - fast w.2 i ≤ hiG i)
    (hR : ∀ w₀ ∈ chartSafe ν, poincareProd ν 1 w₀ = z₀ → ∀ w ∈ chartSafe ν,
      (∀ i, |G i w - G i w₀| ≤ d) → (∀ i, |fast w.2 i - actionVector ν z₀ i| ≤ d + ε) →
      chartAMD w ≤ strongAMD ν z₀ + n * (d + ε) → w ∈ R)
    (hη : ∀ i, ∀ w ∈ R,
      |fderiv ℝ (F i) w (hamiltonianVectorField (liftChartHam ν μ) w)| ≤ η i)
    (hFG : ∀ i, ∀ w ∈ R, lo i ≤ F i w - G i w ∧ F i w - G i w ≤ hi i)
    (hd0 : 0 < d) (hT : ∀ i, η i * T + (hi i - lo i) < d) (hε : ∀ i, hiG i - loG i ≤ ε)
    (hdr : d + ε ≤ r / 2) :
    ∀ J : Set ℝ, J.OrdConnected → (0 : ℝ) ∈ J → ∀ z : ℝ → Phase (n * 2),
      IsMovingSolutionOn ν μ J z → z 0 = z₀ → ∀ t ∈ J, |t| ≤ T →
        StoppedOn ν z₀ δ r z t →
        ‖actionVector ν (z t) - actionVector ν z₀‖ ≤ r / 2
```

**Exactly what changed against the note's §4 sketch.** Each change weakens a hypothesis or binds a free name. No
change strengthens what the certificate must show.

1. **`w₀` was unbound.** `hR` now quantifies over every chart lift: `∀ w₀ ∈ chartSafe ν, poincareProd ν 1 w₀ = z₀ →`.
   - Why: `lpChartLift_of_stopped` picks the lift `w 0` by choice. Its statement pins only `Ψ(w 0) = z₀` (via the
     projection clause) and `Λ(w 0) = Λ(z₀)`.
   - Cost: none for an observable that factors through `Ψ`, such as `G = keplerAction (redMass ν μ) ∘ Ψ`, because
     then `G(w₀)` is the same for every lift.
2. **`hR`'s antecedent gains `∀ i, |Λ_i(w) − Λ_i(z₀)| ≤ d + ε`.** This weakens the hypothesis. The proof has this
   bound anyway, from `hGΛ`.
   - Effect: `R` can be the Λ-box region `R(d + ε)` (cover-friendly), not only a `G`-defined set.
3. **`hGΛ` and `hGc` live on `chartTube ν z₀ r`.** The note had `chartSafe ν ∩ {‖Λ − Λ(z₀)‖ < r}`; the tube adds
   `chartAMD ≤ C(z₀) + n r`.
   - Why it is free: along a stopped orbit the bound holds automatically, by conservation of `L`
     (`strongAMD_le_of_action_drift`).
   - Why it is needed: without an AMD bound the eccentricity is unbounded in `chartSafe`, so the range of `G − Λ`
     is not small and `hGΛ` could not be discharged with a small `ε`.
4. **`hGc` is `ContinuousOn` on the tube, not on `chartSafe ν`.** The reduced action is not continuous on all of
   `chartSafe ν`.
   - `E < 0` does not imply `E^red < 0`: for near-parabolic states `E^red = E + μ|p|²/2` can vanish, and there
     `keplerAction ν'` jumps to `0`.
   - On the tube the HD instance proves continuity (below).

**Proof** (as sketched in the note):
1. Lift the stopped orbit with `lpChartLift_of_stopped`.
2. The stopped conditions put the lift in `chartTube`.
3. On the tube, `|Λ_i(u) − Λ_i(0)| ≤ |G_i(w u) − G_i(w 0)| + ε`.
4. Run the first exit (`amd_exit_forward`/`amd_exit_backward`) on `y = G(w ·) − G(w 0)` at level `d`. While
   `|y| < d`: the Λ-drift is `≤ d + ε`, the AMD is `≤ C₀ + n(d+ε)`, and `w ∈ R` by `hR`. Then the mean value step and
   `hFG` give `|y| ≤ η T + (hi − lo) < d`.
5. Final Λ-drift: `≤ |y t| + ε ≤ d + ε ≤ r/2`.

The structure is that of `stoppedDrift_of_approxIntegrals`, with the same helper `abs_sub_le_of_fderiv_bound`.

## Task 4: the analytic range of `G − Λ` (`ReducedRange`, core and HD)

**Core:**
- `keplerAction_redMass_eq_div_sqrt` (orbital form): `G = Λ / √((1+k)(1 − k(2a/r − 1)))` with `k = μν`. It follows
  from vis-viva, `|p|² = ν²(2/r − 1/a)`, which comes from `orbital_identities`.
- `keplerAction_redMass_sub_bounds`: for an eccentricity bound `e` with `k(1+e) < 1−e`,
  `Λ(1/√X_lo − 1) ≤ G − Λ ≤ Λ(1/√X_hi − 1)`, where `X_lo = (1+k)(1 − k(1−e)/(1+e))` and
  `X_hi = (1+k)(1 − k(1+e)/(1−e))`. It uses `a(1−e) ≤ r ≤ a(1+e)`.
- `chart_ecc_le`: in the chart `L_i = Λ_i − Γ_i`, so `Γ_i ≤ Γmax` and `Λ_i ≥ Λmin` bound `e` by every `e ≥ 0` with
  `1 − e² ≤ (1 − Γmax/Λmin)²`.
- `chart_reducedAction_sub_bounds` combines these on a chart box.
- `mul_one_div_sqrt_sub_one_le` and `le_mul_one_div_sqrt_sub_one` turn the `sqrt` bounds into rational inequalities.

**HD** (`HD11964.ReducedRange`):
- On `R(r)` we have `Λ ∈ [Λlo − r, Λhi + r]` and `Γ_i ≤ cBar + 2r = 0.018`, so `e_c ≤ 93/125` and `e_b ≤ 71/500`.
- `reducedAction_sub_mem_region` proves `loGan_i ≤ G_i − Λ_i ≤ hiGan_i` with:

  | planet | `loGan` | `hiGan` | width |
  |---|---:|---:|---:|
  | c (index 0) | `−2·10⁻⁶` | `1.2·10⁻⁵` | `1.4·10⁻⁵` |
  | b (index 1) | `−1.17·10⁻⁴` | `1.56·10⁻⁴` | `2.73·10⁻⁴` |

- All of this is checked by `norm_num` on the exact rationals.
- `reducedAction_pos` and `continuousOn_reducedAction`: `G > 0` on `R(r)`, hence `E^red < 0` there, hence `G` is
  continuous there.

**Budget consequence (*est.*, arithmetic only).** With `r = 1/250`, `ε = 273·10⁻⁶` gives `d ≤ r/2 − ε = 1.727·10⁻³`
(the plain bridge had `d ≤ 2·10⁻³`). The gain depends on how much the range of `F − G` on `R(d+ε)` shrinks relative
to `F − Λ` (the campaign's ~7×). That range is certificate-side and **not measured here**.

The analytic width at `e_b ≤ 0.142` is about 1.4× the note's first-order figure at the nominal `e_b ≈ 0.1`
(`1.9·10⁻⁴`), because `R(r)` grants the whole AMD budget to b. A cell bound could tighten it only by using a smaller
set than `R(r)`.

Usability check (scratch, not committed): an `ObsDriftData 2` with `ε = 273/10⁶`, `d = 1/600`, `r = 1/250`,
`loG = loGan` and `hiG = hiGan` passes `D.ok = true` by `decide +kernel`.
