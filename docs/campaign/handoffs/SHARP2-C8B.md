## Result

The certified first step is now a theorem, in the form the certifier (C8c) will consume. Nothing is certified yet: no step,
no number and no kernel test exists at this stage.

- **Signatures.** All 51 declarations of the signature file are in the modules verbatim, by a script that compares each
  statement's text (C8a's 24 plus `g1_hybrid_core_R`, `g1_hybrid_core_B`, `KData`, `StepNum`, `StepBounds`, the transferred

  named `restart_n`.
- **`g1_hybrid_R`, `iso_g1_hybrid_R`.** Frozen hypotheses and refined data of `K`, a step with the bounds `(S1)–(S7)`
  (iso: also `ℓ_H`, `d_ω`), the restart numbers, and the numerical conditions conclude the frozen body for `K`. Soundness
  never uses that `ΔK` solves the cohomological equations.
- **`g1_v2A'_hybrid`, `iso_g1_v2A'_hybrid`.** The disjunction: the plain branch or the hybrid branch, by cases. Every
  hypothesis of the plain body is kept and the step data are used only in the second branch, so acceptance is never worse.
  Each closeness is the maximum of the two.

## Approach

- **`StepHyp`** (`Transfer.lean`) collects what the transfer takes, with `K` at frequency `ω` and `K₁` at `ω₁`. Its lemmas give
  every hypothesis of a branch for `K₁`: structure, frames on `T_{ρ₁}` and `ℝⁿ`, the new error and its derivative, `t₁`, `t_A`,
  the twist. The fixed and isoenergetic theorems read from the same lemmas, with `ω₁ = ω` and `ω₁ = s₁ ω*`.
- **`local_le`** turns `norm_torsion_sub_torsionAB_le` into the form of `StepNum.lam0`, `lam1`: `|Fᵀ| ≤ 2n|F|`
  (`norm_transpose_le_two_mul`) and `|Aᵀ + A| ≤ 2M₁ ≤ 4nM₁`.
- **Standing at two frequencies.** The iso proof gets `Standing` at `s ω*` and at `s₁ ω*` from `IsoStanding.setting`; `1 ≤ s₁`
  comes from `ray_step`.
- **The energy.** `energyAverage_step_le` is applied with `d₀ := min d₀ d₀^ℝ`, which is below `μ` by `(S1)`, then bounded by
  `d₀^ℝ`. No hypothesis `d₀^ℝ < μ` is added.
- **The torsion strip in the minimum.** `bite_mono`: `x ↦ x − min {1, (x − ρ∞)/6}` is increasing, so `T_{ρ₁−δ₀'}` lies in
  `T_{ρ−δ₀}` and `RefHypA.tors` supplies `hT`.

## Additions and deviations

1. **`NumA.restartI` (a design gap).** The isoenergetic branch needs `HY = M_{h1} σ_N`, and `RestartA` changes `σ_N`, while
   `NumA.restart` keeps `N.HY`. At `N.restart R` the hypothesis `hHY` of `iso_g1_hybrid_R` holds only if `N.HY = q.Mh1 R.sN`. The
   iso minimum was not in the probe, so the design did not meet this. `NumA.restartI N R Mh1` is `NumA.restart` with
   `HY := Mh1 * R.sN`; `iso_g1_hybrid_R` is unchanged and takes `N₁` generally, and `iso_g1_v2A'_hybrid` and `IHybOkR` use
   `restartI`. **For C8c: the iso checker must use `restartI`, not `restart`.**
2. **`g1_hybrid_B` (added).** The blueprint's theorem covers route B and the signature file stops at its core form. The step
   form is `g1_hybrid_core_B` with the same `StepHyp`. `δ` is a free bite with `0 < ρ₁ − δ`, and `cTh = N₁.cTh`. Its
   `StepBounds` still carries the `T'` bounds `loc0`, `loc1`, which route B does not use.
3. **Not done: isoenergetic route B.** The design's table has no iso route-B target and the signature file none.
   `iso_g1_branch_B` exists, so the core form would be short; R1's hybrid takes route A′, so I left it out.
4. **`linNewErrorIso`, `linNewError_eq_iso` (added).** `bpI:p2s2hc:lin` names `KAM.Iso.Sharp2.Hybrid.linNewErrorIso`, which was
   not in the signature file. It now exists, and `linNewError_eq_iso` proves that `Ẽ_s` is `linNewError` at `s₁ ω*`, the form of
   `StepBounds.lin`.
5. **`StepHyp` has no `tors` field.** `tors₁` takes `hT` as an argument, so route B needs no bound `k.t`.

The blueprint is not edited (additive rule). Items 1–3 want a line in `p2s2-iso-hybrid-cert.tex` and the design note.

## Uncertainties

- **No use yet.** No theorem here has been applied to an actual step; C8c is the first consumer. `StepBounds` or `IHybOkR` may
  want reshaping for the checker. Statements stay as designed until then.
- **Conservative formulas.** As AUDIT-HYBRID-1 F3 says, the hybrid branch does not reproduce a route at `ΔK = 0`. The minimum
  covers that by the first disjunct.
- `hG`, `hG₁` of `torsionAB_step_sub_le` are unused (verbatim signature).
