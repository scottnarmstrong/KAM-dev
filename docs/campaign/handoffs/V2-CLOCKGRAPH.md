## Approach

**Mathematics.** In an extended phase space with a clock (an action `I_l` with `∂_{I_l} H ≡ a`),
the core clock lemma `KAM.Certificate.clock_frequency` gives `A_l(θ) = θ_l + c_l` for the angle
map `A` of the exact torus, so `DA` is triangular. With the free diagonal `∂_i A_i ≥ m > 0`:

* injectivity: equal images have equal clock components, so the points lie on one line
  `s ↦ θ + s eᵢ`, along which `A_i` grows at rate `≥ m` (mean value inequality);
* surjectivity: fix the clock components `φ_l - c_l`; `s ↦ A_i(θ₀ + s eᵢ)` is continuous with
  `g(s + 1) = g(s) + 1` (from `k(θ + m) = k θ + (m, 0)`), so intermediate values hit `φ_i`;
* `DA(θ)` is injective (triangular, diagonal `≥ m` and `1`), so the inverse is continuous
  (`isOpenMap_of_hasStrictFDerivAt_equiv`, `Equiv.toHomeomorphOfContinuousOpen`) and analytic
  (`Homeomorph.contDiff_symm` at order `ω`), as in V2-ADAPT's `DerivNearId.analyticOnNhd_invFun`.

**The weaker graph notion.** `IsAngleGraph k L` bundles the near-identity constant. The clock
criterion gives no such constant (no bound on `∂_l A_i`, `l ≠ i`), so the qualitative content is
isolated as `IsAnalyticAngleGraph k` (analytic, bijective angle map commuting with `ℤⁿ`, analytic
inverse, `DA` injective, `eq_graph`, `range_eq`, periodic analytic `G`, `injective_mod`,
`immersion`); `IsAngleGraph.isAnalyticAngleGraph` maps the old adapter into it. The clock form
`IsClockAngleGraph k i c m` extends it by `IsClockTriangular (torusAngle k) i c m`, which carries
the quantitative slice bound `m |s' - s| ≤ |A_i(θ + s' eᵢ) - A_i(θ + s eᵢ)|` and
`A⁻¹(φ)_l = φ_l - c_l`.

**Certificate level.** Clock slope `a > 0` (SO-2 rotated: `a = c`; SO-3: `a = κ`; T2: `a = 1`):
`CertifiedTorusAt.clock` applies `clock_frequency` to `a⁻¹ c.H` at the frequency `a⁻¹ s∞ ω*`
(`invarianceError_ofReal_mul`, a copy of SO's `invarianceError_const_mul`, which lives in the SO
track); it needs `IsDiophantine γ τ ω*`, `γ > 0`, as every certifier's soundness theorem does.
The diagonal moves from `K` to `K∞` by Cauchy (`norm_fderiv_sub_le_of_real`), loss `disp/ρ∞`.

**Checks.** `checkClock` is syntactic on `HamExpr` (`actionSlope`); `checkClockGraphReal` reuses
V2-ADAPT-FIX's unconverted derivative model at weight `1` for the one diagonal entry;
`checkClockGraph` is SO's SOS lower bound on the `(i, i)` entry of the `DK` models
(`clockDiagModel`, definitionally SO's `soGraphMonoModel` at `n = 2`, `i = 0`). Neither diagonal
check has a `0 < mono` conjunct: the margin `disp < mono ρ∞` alone gives `mono - disp/ρ∞ > 0`,
and leaving it out makes `checkSoGraph ⇒ checkClockGraph` a projection.

```lean
module

public import KAM.Application.ClockGraphCheck
public import KAM.SpinOrbit.Graph.Cert
public import KAM.SpinOrbit.Rotated
public import KAM.SpinOrbit.Lock.Coords.HamExpr
public import KAM.SpinOrbit.Lock.Graph

public section

open KAM KAM.Certificate KAM.Application KAM.SpinOrbit KAM.SpinOrbit.Lock

/-- The SO diagonal model is the clock diagonal model. -/
example {α : Type} [CertArith α] (g : SoGraphCert α) :
    soGraphMonoModel g = clockDiagModel 2 g.base.emb g.base.weight g.base.piEnc 0 := rfl

/-- `checkSoGraph` implies the SOS clock check. -/
theorem checkClockGraph_of_checkSoGraph {α : Type} [CertArith α] (g : SoGraphCert α)
    (h : checkSoGraph g = true) : checkClockGraph g.base 0 g.mono g.mono₀ g.sosMono = true := by
  simp only [checkSoGraph, Bool.and_eq_true] at h
  simp only [checkClockGraph, Bool.and_eq_true]
  exact ⟨h.1.1.1, h.1.1.2⟩

theorem so_slope : actionSlope 1 soHamExpr = some 1 := by decide +kernel
theorem soRot_slope : actionSlope 1 soRotHamExpr = some 1 := by decide +kernel
theorem lock_slope :
    actionSlope 1 (HamExpr.mul (.const (5 / 4)) (lockHamExpr (1 / 3) [1 / 2, 1 / 5])) =
      some (5 / 4) := by decide +kernel

theorem checkClock_soRot {α : Type} [CertArith α] (g : SoGraphCert α) {c : ℚ} (hc0 : 0 < c)
    (hham : g.base.ham = soRotHamExprScaled c) : checkClock g.base 0 c = true := by
  have h1 : actionSlope 1 (soRotHamExprScaled c) = some c := by
    simp [soRotHamExprScaled, actionSlope, hamConstVal?, soRot_slope]
  simp [checkClock, hham, h1, hc0, List.all_cons, List.finRange_succ]

/-- An SO-2 rotated-frame certificate through the clock adapter. -/
example {α : Type} [CertArith α] [LawfulCertArith α] (g : SoGraphCert α) {c : ℚ} (hc0 : 0 < c)
    (hham : g.base.ham = soRotHamExprScaled c) (hs : checkStatic g.base = true)
    (hh : checkHamBounds g.base = true) (hg : checkSoGraph g = true) {ωstar : Fin 2 → ℝ}
    (hT : CertifiedTorus g.base ωstar)
    (hdio : IsDiophantine (g.base.params.γ : ℝ) (g.base.params.tau : ℝ) ωstar) :
    ∃ (Kinf : (Fin 2 → ℂ) → (Fin 2 → ℂ) × (Fin 2 → ℂ)) (sinf : ℝ),
      CertifiedTorusAt g.base ωstar Kinf sinf ∧ sinf * ωstar 1 = c ∧ ∃ cc : Fin 2 → ℝ,
      IsClockAngleGraph (realRestriction Kinf) 0 cc
        ((g.mono : ℝ) - (g.base.params.disp : ℝ) / g.base.params.rhoInf) := by
  obtain ⟨Kinf, sinf, hT', -, hf, hG⟩ := hT.exists_clockGraph_of_checks hs hh
    (checkClock_soRot g hc0 hham) (by exact_mod_cast (checkStatic_sound hs).hγ) hdio
    (.inr ⟨_, _, checkClockGraph_of_checkSoGraph g hg⟩)
  exact ⟨Kinf, sinf, hT', hf 1 (by decide), hG⟩

/-- An SO-3 lock certificate through the clock adapter (clock slope `κ`). -/
example {α : Type} [CertArith α] [LawfulCertArith α] (g : LockGraphCert α) (hκ : 0 < g.κ)
    (hham : g.graph.base.ham = .mul (.const g.κ) (lockHamExpr g.Ω g.cs))
    (hslope : actionSlope 1 (lockHamExpr g.Ω g.cs) = some 1)
    (hs : checkStatic g.graph.base = true)
    (hnv : g.graph.base.ham.NonvanishingOn g.graph.base.D)
    (hg : checkSoGraph g.graph = true) {ωstar : Fin 2 → ℝ}
    (hT : CertifiedTorus g.graph.base ωstar)
    (hdio : IsDiophantine (g.graph.base.params.γ : ℝ) (g.graph.base.params.tau : ℝ) ωstar) :
    ∃ (Kinf : (Fin 2 → ℂ) → (Fin 2 → ℂ) × (Fin 2 → ℂ)) (sinf : ℝ),
      CertifiedTorusAt g.graph.base ωstar Kinf sinf ∧ sinf * ωstar 1 = g.κ ∧
      ∃ cc : Fin 2 → ℝ, IsClockAngleGraph (realRestriction Kinf) 0 cc
        ((g.graph.mono : ℝ) - (g.graph.base.params.disp : ℝ) / g.graph.base.params.rhoInf) := by
  have hH := isRealHolo_of_nonvanishing g.graph.base hnv
  have hclk : checkClock g.graph.base 0 g.κ = true := by
    have h1 : actionSlope 1 g.graph.base.ham = some g.κ := by
      simp [hham, actionSlope, hamConstVal?, hslope]
    simp [checkClock, h1, hκ, List.finRange_succ]
  obtain ⟨ha, hclock⟩ := checkClock_sound hH hclk
  obtain ⟨hmono, hm⟩ := checkClockGraph_sound hs (checkClockGraph_of_checkSoGraph g.graph hg)
  obtain ⟨Kinf, sinf, hT', -, hf, hG⟩ := hT.exists_clockGraph hs hH ha hclock
    (by exact_mod_cast (checkStatic_sound hs).hγ) hdio hmono hm
  exact ⟨Kinf, sinf, hT', hf 1 (by decide), hG⟩
```
