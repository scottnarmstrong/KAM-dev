### 1. The bridge (design §4, with `hF` on an open `O ⊇ R`)

```lean
theorem stoppedDrift_of_approxIntegrals {ν : Fin n → ℝ} {U : Set (Fin n → ℝ)}
    {z₀ : Phase (n * 2)} {δ r : ℝ} (hd : LiftData ν U z₀ δ r) {μ T d : ℝ}
    (F : Fin n → Phase (n + n) → ℝ) (R O : Set (Phase (n + n))) (η lo hi : Fin n → ℝ)
    (hO : IsOpen O) (hRO : R ⊆ O) (hF : ∀ i, DifferentiableOn ℝ (F i) O)
    (hR : ∀ w ∈ chartSafe ν, (∀ i, |fast w.2 i - actionVector ν z₀ i| ≤ d) →
      chartAMD w ≤ strongAMD ν z₀ + n * d → w ∈ R)
    (hη : ∀ i, ∀ w ∈ R,
      |fderiv ℝ (F i) w (hamiltonianVectorField (liftChartHam ν μ) w)| ≤ η i)
    (hG : ∀ i, ∀ w ∈ R, lo i ≤ F i w - fast w.2 i ∧ F i w - fast w.2 i ≤ hi i)
    (hd0 : 0 < d) (hT : ∀ i, η i * T + (hi i - lo i) < d) (hdr : d ≤ r / 2) :
    ∀ J : Set ℝ, J.OrdConnected → (0 : ℝ) ∈ J → ∀ z : ℝ → Phase (n * 2),
      IsMovingSolutionOn ν μ J z → z 0 = z₀ → ∀ t ∈ J, |t| ≤ T →
        StoppedOn ν z₀ δ r z t →
        ‖actionVector ν (z t) - actionVector ν z₀‖ ≤ r / 2
```

- The conclusion is, verbatim, the `hstop` hypothesis of `strongFirstExit_of_stopped_drift`. `StoppedOn` is
  LP-LIFT's name for its antecedent; the two are definitionally equal, and `noCrossing_of_stoppedDrift` feeds one
  to the other.
- Changes from design §4, all weakenings:
  - `hF` is `DifferentiableOn` on an open `O ⊇ R` (audit §2), not `ContDiffOn 1` on `chartSafe`. `O ⊆ chartSafe`
    is not needed.
  - `hper` (periodicity of `F`) is dropped: the bridge evaluates `F` along one chart lift. Periodicity is needed
    only to turn a cover of a fundamental domain into a bound on `R`, which is part B's cover.
  - `hd0 : 0 < d` is added, a decided inequality.
- **Proof.**
  1. `lpChartLift_of_stopped` lifts the stopped orbit.
  2. A one-dimensional first exit (`amd_exit_forward` and `amd_exit_backward`) runs on the drift curve
     `y(u) = Λ(w u) − Λ(z₀)`, with `V` the open sup-ball of radius `d` and `C = {|y_i| ≤ η_i T + hi_i − lo_i}`.
  3. While `y ∈ V`, `strongAMD_sub_eq_sum` together with `lpChart_strongAMD` gives `chartAMD ≤ C(z₀) + n d`. So
     `hR` puts the lift in `R`.
  4. The mean value inequality (`abs_sub_le_of_fderiv_bound`) and `hG` then give `y ∈ C`.

### 2. The corollary (design §2 shape, any planar system)

```lean
structure DriftData (n : ℕ) where
  eta : Fin n → ℚ
  lo : Fin n → ℚ
  hi : Fin n → ℚ
  T : ℚ
  d : ℚ
  r : ℚ

def DriftData.ok (D : DriftData n) : Bool :=
  decide (0 < D.T) && decide (0 < D.d) && decide (2 * D.d ≤ D.r) &&
    decide (∀ i, D.eta i * D.T + (D.hi i - D.lo i) < D.d)

theorem noCrossing_of_approxIntegrals (hn : 2 ≤ n) (ν : Fin n → ℝ) (hν : ∀ i, 0 < ν i)
    (U : Set (Fin n → ℝ)) (hUc : IsCompact U) (hUch : U ⊆ chamber ν) (δ : ℝ) (hδ : 0 < δ) :
    ∃ dStar dPair : ℝ, 0 < dStar ∧ 0 < dPair ∧
      ∀ (D : DriftData n), D.ok = true → ∀ (μ : ℝ) (z₀ : Phase (n * 2)),
        LiftData ν U z₀ δ D.r →
        ∀ (F : Fin n → Phase (n + n) → ℝ) (R O : Set (Phase (n + n))),
          IsOpen O → R ⊆ O → (∀ i, DifferentiableOn ℝ (F i) O) →
          (∀ w ∈ chartSafe ν, (∀ i, |fast w.2 i - actionVector ν z₀ i| ≤ D.d) →
            chartAMD w ≤ strongAMD ν z₀ + n * D.d → w ∈ R) →
          (∀ i, ∀ w ∈ R,
            |fderiv ℝ (F i) w (hamiltonianVectorField (liftChartHam ν μ) w)| ≤ D.eta i) →
          (∀ i, ∀ w ∈ R, (D.lo i : ℝ) ≤ F i w - fast w.2 i ∧ F i w - fast w.2 i ≤ D.hi i) →
          ∃ z : ℝ → Phase (n * 2), z 0 = z₀ ∧
            IsMovingSolutionOn ν μ (Icc (-(D.T : ℝ)) D.T) z ∧
            MovingUniqueOn ν μ (Icc (-(D.T : ℝ)) D.T) z ∧
            ∀ t ∈ Icc (-(D.T : ℝ)) D.T,
              (∀ i, dStar ≤
                keplerAxis ν (z t) i * (1 - planeLength (keplerEccVector ν (z t) i))) ∧
              (∀ a : AdjIdx n, dPair ≤ keplerAxis ν (z t) a.upperIdx *
                  (1 - planeLength (keplerEccVector ν (z t) a.upperIdx)) -
                keplerAxis ν (z t) a.1 * (1 + planeLength (keplerEccVector ν (z t) a.1))) ∧
              (∀ i, dStar ≤ planeLength (bodyVector (z t).1 i)) ∧
              (∀ i j, i ≠ j →
                dPair ≤ planeLength (bodyVector (z t).1 i - bodyVector (z t).1 j))
```

- **The hypotheses** fall into four kinds:
  - typing data: `ν`, `U`, `δ`, `μ`, `z₀`, `F`, `R`, `O`;
  - source premises: `hν`, `hUc`, `hUch`, `hδ`, and LP's `LiftData`;
  - the decided `D.ok = true` (`DriftData.ok_spec` turns it into the real inequalities);
  - the certificate's per-region bounds `hη` and `hG`, with the inclusion `hR` and the differentiability on `O`.
  None is conclusion-shaped. `hη`/`hG` are the interface to part B (below).
- **The conclusion** is LP0's four separations along the solution, verbatim from `planar_strongAMD_barrier`.
  `dStar` and `dPair` are LP0's constants for `(ν, U, δ/2)`, chosen before `D`, `μ` and `z₀`.
- **The proof.** `noCrossing_of_stoppedDrift` (conditional helper: LP-CONF's `hstop` is an explicit hypothesis)
  composes `strongFirstExit_of_stopped_drift` with LP0, using `sourceStrongAMD_eq` and `orderedStrongThreshold_eq`
  on the barrier states. `noCrossing_of_approxIntegrals` then discharges `hstop` with item 1.

### Rotation invariance (design §9, core `Rotation.lean`)

```lean
def chartRot (θ : ℝ) (w : Phase (n + n)) : Phase (n + n) :=
  assemble (fast w.2) (fun i => fast w.1 i + θ)
    (fun i => Real.sin θ * slow w.1 i + Real.cos θ * slow w.2 i)
    (fun i => Real.cos θ * slow w.1 i - Real.sin θ * slow w.2 i)

theorem poincareProd_chartRot (m : Fin n → ℝ) (κ θ : ℝ) {w : Phase (n + n)}
    (hw : w ∈ poincareProdDom n) :
    poincareProd m κ (chartRot θ w) = SecularForm.rotatePhysical θ (poincareProd m κ w)
theorem liftChartHam_chartRot (ν : Fin n → ℝ) (μ θ : ℝ) {w : Phase (n + n)}
    (hw : w ∈ poincareProdDom n) : liftChartHam ν μ (chartRot θ w) = liftChartHam ν μ w
theorem bracket_bound_of_rotation {ν : Fin n → ℝ} (hν : ∀ i, 0 < ν i) (μ : ℝ)
    {F : Phase (n + n) → ℝ} {O : Set (Phase (n + n))} (hO : IsOpen O) (hOs : O ⊆ chartSafe ν)
    (hF : DifferentiableOn ℝ F O)
    (hFrot : ∀ θ, ∀ w ∈ O, chartRot θ w ∈ O ∧ F (chartRot θ w) = F w)
    {R S : Set (Phase (n + n))} (hRO : R ⊆ O) (hRS : ∀ w ∈ R, ∃ θ, chartRot θ w ∈ S) {η : ℝ}
    (hS : ∀ w ∈ S, |fderiv ℝ F w (hamiltonianVectorField (liftChartHam ν μ) w)| ≤ η) :
    ∀ w ∈ R, |fderiv ℝ F w (hamiltonianVectorField (liftChartHam ν μ) w)| ≤ η
```

- **The chart equivariance** reuses the per-planet identity `poincare_rotate` and `ofPlanets_map` of
  `KAM/Planetary/SecularForm/Symmetry.lean` (read only).
- **The vector field** is equivariant by `hamiltonianVectorField_comp`. It is generic: a map with symplectic,
  surjective derivative and `H ∘ R = H` near `w`. The proof uses `symplecticForm_hamiltonianVectorField` and the
  nondegeneracy of the symplectic form.

## The interface to part B (kamx-hd-layer)

For HD 11964 at `d = D.d ≤ 1/1000`, part B's cells and cover must deliver, for `F : Fin 2 → Phase (2 + 2) → ℝ`
and an open `O ⊇ region D.d` on which every `F i` is differentiable:

1. `∀ i, ∀ w ∈ region D.d, |fderiv ℝ (F i) w (hamiltonianVectorField (liftChartHam nu mu) w)| ≤ D.eta i`;
2. `∀ i, ∀ w ∈ region D.d, D.lo i ≤ F i w - fast w.2 i ∧ F i w - fast w.2 i ≤ D.hi i`.

- **Representatives are enough.** Under rotation invariance of `F` and `O` (`hFrot`), it suffices to prove 1–2 on
  representatives `S` (for example `η_b = 0`) with `∀ w ∈ region D.d, ∃ θ, chartRot θ w ∈ S`. That is
  `bracket_bound_of_rotation` and `range_bound_of_rotation`.
- **`F` is any function.** Nothing is assumed about how `F` is built: the Lie series, the projections `Π_S` and
  the Kepler solve stay inside part B. `fderiv` along `X_H` is the bracket `{F_i, H∘Ψ}` with LP's sign
  convention (`hamiltonianVectorField = (∂_I H, −∂_θ H)`).
- **Drift data.** `D.ok = true` and `D.r = 1/250` close the statement. For the 10³ yr rung the design's numbers
  are `T = 6742`, `d = 1/1000`, and `η, lo, hi` from the cells.
