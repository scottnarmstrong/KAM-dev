## Approach (blueprint `bp:p2s:torsion-identity`, `frame-bounds`, `geometry`, `torsion-bound`)

- **`torsion_identity`.**
  - **Gram inverse.** The derivative of `θ ↦ (gramMatrix K θ)⁻¹` comes from differentiating `B·G = 1`, which is
    eventually constant near θ.
    - `fderiv_matrix_mul_apply` gives `(∂B)G + B∂G = 0`, and then `∂B = −B(∂G)B` follows using `G B = 1`.
    - No `Ring.inverse` calculus was needed.
  - **Tangent frame.** `fi_dL` (`KAM/Apost/Identities.lean:269`) is stated for the standing frequency of `hS`.
    `fderiv_tangentMat_eq` reproves it at any `ω'`, with the same proof; only ω-free Hamiltonian facts are used.
  - **Expansion.** The torsion is expanded from `torsion_eq_mat` and `NᵀΩ₀ = BLᵀ`. The rest is a pure matrix identity
    (`torsion_alg`: `simp only [transpose_*, mul_sub, sub_mul, mul_add, add_mul, mul_neg, mul_assoc]; abel`).
- **`frame_bounds`.** The sizes come from `FrameAux.norm_tangentMat`, `norm_transpose_le_two_mul`,
  `norm_omegaZeroMatrix_mul`, `norm_mul_omegaZeroMatrix` and `norm_fromCols_le_add`, and `Aᵀ = Ω₀AΩ₀` from
  `ham_symplectic`.
- **`geometry_sep`.** It follows the proof of `KAM.Apost.geometry`:
  - `geo_de` for DE;
  - separate-size copies for `∂_ωΩ_K` and `E_red`;
  - `CohData.apriori` on `T_{r−δ}` for `Ω_K`;
  - `fi_symDefect` with `max{1, σ_B²}` for `E_sym`.
- **`torsion_bound`.**
  - `torsion_identity` gives T = 𝒯(A, L, B, DE).
  - `geo_de` (loss δ) bounds DE, and `geometry_sep` with loss δ/2 bounds Ω_K on `T_{r−δ}`
    (`half_loss_eq`: `(δ/2)^{κ+1} = δ^{κ+1}/2^{κ+1}`).
  - `norm_torsionPoly_le` and the arithmetic finish it: the first part equals `C_T0 + C_T1 ε/δ` exactly, and the
    second is ≤ `C_T2 ε/(γδ^{κ+1})` using `ε/δ ≤ 1`.

  does not use it; this is noted only for A1/A5 integration.
