## The exact statement (before the proof)

New files: `KAM/Application/LambdaDrift/Poisson.lean` (a real canonical bracket on `Phase d`, with antisymmetry,
the derivation rule for constant directions and the Jacobi identity) and `KAM/Application/LambdaDrift/LieRemainder.lean`
(the identity). Namespace `KAM.Application.LambdaDrift`.

```lean
/-- The canonical bracket `{a, b}(w) = Da(w) X_b(w)` (LP's `hamiltonianVectorField`, angles first). The bridge's
rate `fderiv ℝ (F i) w (hamiltonianVectorField H w)` is `pb (F i) H w` by definition. -/
def pb (a b : Phase d → ℝ) (w : Phase d) : ℝ := fderiv ℝ a w (hamiltonianVectorField b w)

/-- The derivative along a constant vector. -/
def dirDeriv (v : Phase d) (a : Phase d → ℝ) (w : Phase d) : ℝ := fderiv ℝ a w v

/-- The direction of the angle conjugate to the action `w.2 k`. -/
def angleDir (k : Fin d) : Phase d := (Pi.single k 1, 0)

/-- The order-2 approximate integral of the action `w.2 k` (truncated Lie series
`exp(L_{-χ₁}) exp(L_{-χ₂}) I_k` to second order): `F = I_k + D_k χ₁ + D_k χ₂ − ½ {D_k χ₁, χ₁}`. -/
def approxIntegral₂ (k : Fin d) (χ₁ χ₂ : Phase d → ℝ) : Phase d → ℝ :=
  fun y => y.2 k + dirDeriv (angleDir k) χ₁ y + dirDeriv (angleDir k) χ₂ y -
    pb (dirDeriv (angleDir k) χ₁) χ₁ y / 2

/-- The order-1 residual `r₁ = P − {χ₁, h}` (for `h = h(Λ)`, `{χ₁, h} = ω·∂_λ χ₁`). -/
def residual₁ (h P χ₁ : Phase d → ℝ) : Phase d → ℝ := fun y => P y - pb χ₁ h y

/-- The order-2 residual `r₂ = {P − ½ {χ₁, h}, χ₁} − {χ₂, h}`. -/
def residual₂ (h P χ₁ χ₂ : Phase d → ℝ) : Phase d → ℝ :=
  fun y => pb (fun z => P z - pb χ₁ h z / 2) χ₁ y - pb χ₂ h y

/-- **The order-2 Lie remainder identity** (design §6.2). For `H = h + P` with `h` independent of the angle
`k`, and smooth `h, P, χ₁, χ₂` on an open `O`, at every `w ∈ O`:
`{F, H} = −D_k r₁ − D_k r₂ + {D_k r₁, χ₁} + {D_k χ₂, P} − ½ {{D_k χ₁, χ₁}, P}`. -/
theorem pb_approxIntegral₂ {k : Fin d} {h P χ₁ χ₂ : Phase d → ℝ} {O : Set (Phase d)}
    (hO : IsOpen O) (hh : ∀ y, fderiv ℝ h y (angleDir k) = 0)
    (hhs : ContDiffOn ℝ ∞ h O) (hPs : ContDiffOn ℝ ∞ P O)
    (h₁ : ContDiffOn ℝ ∞ χ₁ O) (h₂ : ContDiffOn ℝ ∞ χ₂ O) {w : Phase d} (hw : w ∈ O) :
    pb (approxIntegral₂ k χ₁ χ₂) (fun y => h y + P y) w =
      -dirDeriv (angleDir k) (residual₁ h P χ₁) w - dirDeriv (angleDir k) (residual₂ h P χ₁ χ₂) w +
        pb (dirDeriv (angleDir k) (residual₁ h P χ₁)) χ₁ w + pb (dirDeriv (angleDir k) χ₂) P w -
        pb (pb (dirDeriv (angleDir k) χ₁) χ₁) P w / 2
```

- **No hypothesis relates `χ₁`, `χ₂` to `h`, `P`.** The identity holds for all smooth functions; the residuals
  `r₁`, `r₂` are *defined* as what the homological equations leave over.
  - With `ω·∂_λ χ₁ = Π_S P` and `ω·∂_λ χ₂ = Π_S {P − ½ Π_S P, χ₁}`, `r₁ = (1 − Π_S) P` and
    `r₂ = (1 − Π_S) G₂` are Fourier tails.
  - Their angle averages carry no `D_k`, so `D_k r_j` is the derivative of a tail.
  - The three bracket terms are of order `μ`·tail, `μ³` and `μ³`.
- **No cancellation is left to the kernel.** Every term on the right is bounded with relative accuracy `O(1)`.
- **An order-1 companion** (`F = I_k + D_k χ₁`): `{F, H} = −D_k r₁ + {D_k χ₁, P}`.
- **A chart corollary** for the bridge: `H = liftChartHam ν μ`, `h = hProd 1 ν` (the Kepler part,
  angle-independent), `P = H − h`, `O ⊆ chartSafe ν` open. It gives the bridge's
  `fderiv ℝ (F i) w (hamiltonianVectorField (liftChartHam ν μ) w)` as the right-hand side above, with
  `k = Fin.castAdd n i` (the action `Λ_i`, angle `λ_i`).

## The interface to the cell check (kamx-hd-layer), to be agreed through the orchestrator

For each planet `i`, with `k = Fin.castAdd n i`, the cell check must certify on each cell `c`, and hence on
`region D.d` through the cover and `bracket_bound_of_rotation`:

1. `|D_k r₁| ≤ a₁`, `|D_k r₂| ≤ a₂`, `|{D_k r₁, χ₁}| ≤ a₃`, `|{D_k χ₂, P}| ≤ a₄`, `|{{D_k χ₁, χ₁}, P}| ≤ a₅`.
   Then `|{F_i, H}| ≤ a₁ + a₂ + a₃ + a₄ + a₅ / 2 =: η_i`. That is the bridge's `hη` with `D.eta i ≥ η_i`.

   `hG`.

`O ⊇ region D.d`, and rotation-invariant for the cover modulo rotation. The drift data are closed by `D.ok = true`, decided with `decide +kernel`: plain `decide` gets stuck on
