## Design

**The set.** `χ*(w)` integrates `P` over every fast angle at the slow variables and actions of `w`. So `χ*` is
smooth on an open set `U` that is **angle-saturated** (`withAngles w λ ∈ U`) and on which `P` is smooth. For HD
11964:
- **The set.** `openHD = {w : Λ_i ∈ (Λlo_i − 1/250, Λhi_i + 1/250), chartAMD w < 1/50}`.
- **Open and saturated.** It constrains only the actions and the slow variables.
- **Inside `chartSafe ν`.** Take the initial state `z₀` of `initial_of_chart` at the action box point nearest
  `Λ(w)`, with circular orbits; it has LP-LIFT data (`HD11964.liftData`).
  - `zeroAngle_mem_liftQ` and `mem_chartSafe_of_liftQ` (LP lane) put `w` in `chartSafe` at every angle, since
    `‖Λ(w) − Λ(z₀)‖ ≤ 1/250 = r` and `chartAMD w < 1/50 ≤ Λ_c − δ/4 ≈ 0.046`.
- **Contains `R(d)` for `d ≤ 1/500`**, because `Cbar + 2d ≤ 0.014 < 1/50`.

**(0) Smooth parametric integrals.** Mathlib has the first derivative under the integral
(`hasFDerivAt_integral_of_dominated_of_fderiv_le`), but no `C^∞` statement. It is proved by induction on the order,
with `contDiffOn_succ_iff_fderiv_of_isOpen` and the domination from compactness of `[0, 1]`. Applied twice, it
handles the double integral.

**(1) Smoothness.**
- `chartCoeff P k` is `C^∞` on `U` by (0); its integrand `P (withAngles w (2πt)) e(−k·t)` is jointly smooth.
- `chiStar` and `projS` are `C^∞` as finite sums of products, provided `frq` is smooth and the divisors don't
  vanish.
- For HD 11964: `P = chartPert ν μ` is smooth on `chartSafe ⊇ openHD`, and `ω = keplerFreq ν` (`ν_i³/Λ_i³`).
  - `χ₁ = χ*(P)`.
  - `G₂ = {P − ½ Π_S P, χ₁}` is smooth (`contDiffAt_pb`).
  - `χ₂ = χ*(G₂)`.
  - `differentiableOn_approxIntegral₂` (R1) gives the bridge's `hF` on `openHD`.

**(2) The homological equation.**
- `h = hProd 1 ν` depends only on `Λ`, so `{χ, h} = Σ_i ω_i ∂_{λ_i} χ` with `ω = keplerFreq ν`.
- Each term of `χ*` depends on the angles only through `e^{ik·λ}`. Its `ω·∂_λ` brings down `i k·ω`, which cancels
  the divisor: `{χ*, h} = Π_S P`.
- With `S` symmetric and `0 ∉ S`, `Π_S P` is the exact Fourier projection: real, with coefficients `P̂_k` on `S`.
  So `(1 − Π_S) P` has no modes in `S`.
- Then `r₁ = P − {χ₁, h} = (1 − Π_S) P`.
- For `r₂`: `{χ₁, h} = Π_S P` holds on the open `U`, so the derivatives agree there and
  `r₂ = {P − ½ Π_S P, χ₁} − {χ₂, h} = G₂ − Π_S G₂`.

**(2e) The small divisors, explicit.**
- `modesHD` is `S = {k ≠ 0 : |k_c| ≤ 80, |k_b| ≤ 20}`, symmetric.
- On `openHD`, `ω_c/ω_b = (ν_c/ν_b)³(Λ_b/Λ_c)³ ∈ [41, 64] > 20 ≥ |k_b|`. Hence `|k·ω| ≥ ω_b` for every `k ∈ S`:
  - for `k_c = 0`, `|k_b| ≥ 1`;
  - for `k_c ≠ 0`, `|k·ω| ≥ ω_c − 20 ω_b ≥ 21 ω_b`.
- `ω_b ≥ 1/(Λhi_b + 1/250)³`. The smallest divisor is at `k = (0, ±1)`. There is no resonance in `S`.

@[expose] public noncomputable section

open Set KAM KAM.Planetary KAM.Planetary.StrongAMD KAM.Application.LambdaDrift
open scoped Real ContDiff

namespace HD11964.Cover

/-! ## Definitions -/

/-- A set of chart states closed under changing the fast angles. -/
def IsAngleSaturated (U : Set (Phase (2 + 2))) : Prop := ∀ w ∈ U, ∀ lam, withAngles w lam ∈ U

/-- The Fourier projection `Π_S P = Re Σ_{k ∈ S} P̂_k e^{i k·λ}` (for a symmetric `S`, the sum is
real). -/
def projS (S : Finset (Fin 2 → ℤ)) (P : Phase (2 + 2) → ℝ) (w : Phase (2 + 2)) : ℝ :=
  (∑ k ∈ S, chartCoeff P k w * charE k (fun i => ((fast w.1 i / (2 * π) : ℝ) : ℂ))).re

/-- The Kepler frequencies `ω_i(Λ) = ν_i³/Λ_i³ = ∂h/∂Λ_i` of `h = hProd 1 ν`. -/
def keplerFreq (ν : Fin 2 → ℝ) (Λ : Fin 2 → ℝ) : Fin 2 → ℝ := fun i => ν i ^ 3 / Λ i ^ 3

/-- **The mode set of HD 11964**: `0 < |k|`, `|k_c| ≤ 80`, `|k_b| ≤ 20` (planet `c` is index 0). -/
def modesHD : Finset (Fin 2 → ℤ) :=
  ((Finset.Icc (-80 : ℤ) 80 ×ˢ Finset.Icc (-20 : ℤ) 20).image fun p => ![p.1, p.2]).erase 0

/-- **The open set of the bridge** for HD 11964: actions within `1/250` of the box (open), chart
AMD below `1/50`, every angle. -/
def openHD : Set (Phase (2 + 2)) :=
  {w | (∀ i, lamLo i - 1 / 250 < fast w.2 i ∧ fast w.2 i < lamHi i + 1 / 250) ∧ chartAMD w < 1 / 50}

/-! ## (0) Smooth parametric integrals -/

/-- (0) **`C^∞` parametric interval integrals**: if `(x, t) ↦ G x t` is `C^∞` on `U × ℝ`, `U`
open, then `x ↦ ∫_a^b G x t dt` is `C^∞` on `U`. -/
def ContDiffOnIntervalIntegral : Prop :=
  ∀ (H E : Type) [NormedAddCommGroup H] [NormedSpace ℝ H] [NormedAddCommGroup E]
    [NormedSpace ℝ E] [CompleteSpace E] (U : Set H) (G : H → ℝ → E) (a b : ℝ), IsOpen U →
    ContDiffOn ℝ ∞ (fun p : H × ℝ => G p.1 p.2) (U ×ˢ univ) →
    ContDiffOn ℝ ∞ (fun x => ∫ t in a..b, G x t) U

/-! ## (1) Smoothness of `χ*` -/

/-- (1a) The Fourier coefficients of a function smooth on an open angle-saturated set are smooth
there. -/
def ContDiffOnChartCoeff : Prop :=
  ∀ (U : Set (Phase (2 + 2))) (P : Phase (2 + 2) → ℝ) (k : Fin 2 → ℤ), IsOpen U →
    IsAngleSaturated U → ContDiffOn ℝ ∞ P U → ContDiffOn ℝ ∞ (fun w => chartCoeff P k w) U

/-- (1b) **`χ*` and `Π_S P` are smooth** on an open angle-saturated set where `P` and `ω` are
smooth and no divisor `k·ω(Λ)`, `k ∈ S`, vanishes. -/
def ContDiffOnChiStar : Prop :=
  ∀ (U : Set (Phase (2 + 2))) (S : Finset (Fin 2 → ℤ)) (frq : (Fin 2 → ℝ) → Fin 2 → ℝ)
    (P : Phase (2 + 2) → ℝ), IsOpen U → IsAngleSaturated U → ContDiffOn ℝ ∞ P U →
    (∀ w ∈ U, ContDiffAt ℝ ∞ frq (fast w.2)) →
    (∀ k ∈ S, ∀ w ∈ U, ∑ i, (k i : ℝ) * frq (fast w.2) i ≠ 0) →
    ContDiffOn ℝ ∞ (chiStar S frq P) U ∧ ContDiffOn ℝ ∞ (projS S P) U

/-- (1c) **The HD open set**: open, angle-saturated, inside `chartSafe ν`, containing `R(d)` for
`0 ≤ d ≤ 1/500`. -/
def OpenHDFacts : Prop :=
  IsOpen openHD ∧ IsAngleSaturated openHD ∧ openHD ⊆ chartSafe nu ∧
    ∀ d : ℝ, 0 ≤ d → d ≤ 1 / 500 → region d ⊆ openHD

/-- (1d) **The bridge's `hF` for HD 11964**: with `χ₁ = χ*(P)`, `G₂ = {P - ½ Π_S P, χ₁}` and
`χ₂ = χ*(G₂)` (`S = modesHD`, the Kepler frequencies), `χ₁`, `χ₂` and `F_i = approxIntegral₂` are
smooth (resp. differentiable) on `openHD`. -/
def ContDiffOnChiHD : Prop :=
  let P := chartPert nu mu
  let χ₁ := chiStar modesHD (keplerFreq nu) P
  let G₂ := pb (fun y => P y - projS modesHD P y / 2) χ₁
  let χ₂ := chiStar modesHD (keplerFreq nu) G₂
  ContDiffOn ℝ ∞ χ₁ openHD ∧ ContDiffOn ℝ ∞ χ₂ openHD ∧
    ∀ i : Fin 2, DifferentiableOn ℝ (approxIntegral₂ (Fin.castAdd 2 i) χ₁ χ₂) openHD

/-! ## (2) The order-2 homological equation -/

/-- (2a) **The homological equation**: `{χ*, h} = Π_S P` for the Kepler part `h = hProd 1 ν`
(`ω = keplerFreq ν`), on an open angle-saturated set of the chart domain. -/
def HomologicalEq : Prop :=
  ∀ (ν : Fin 2 → ℝ) (U : Set (Phase (2 + 2))) (S : Finset (Fin 2 → ℤ)) (P : Phase (2 + 2) → ℝ),
    IsOpen U → IsAngleSaturated U → U ⊆ poincareProdDom 2 → ContDiffOn ℝ ∞ P U →
    (∀ k ∈ S, ∀ w ∈ U, ∑ i, (k i : ℝ) * keplerFreq ν (fast w.2) i ≠ 0) →
    ∀ w ∈ U, pb (chiStar S (keplerFreq ν) P) (hProd 1 ν) w = projS S P w

/-- (2b) **`(1 - Π_S) P` is a pure tail**: for a symmetric `S` without `0`, its Fourier
coefficients vanish on `S`. -/
def ProjSTail : Prop :=
  ∀ (U : Set (Phase (2 + 2))) (S : Finset (Fin 2 → ℤ)) (P : Phase (2 + 2) → ℝ),
    IsAngleSaturated U → ContinuousOn P U → (∀ k ∈ S, -k ∈ S) → 0 ∉ S →
    ∀ k ∈ S, ∀ w ∈ U, chartCoeff (fun y => P y - projS S P y) k w = 0

/-- (2c) **`r₁` is the tail**: with `χ₁ = χ*(P)`, `residual₁ = P - Π_S P` on `U`, and its Fourier
coefficients on `S` vanish. -/
def Residual₁Tail : Prop :=
  ∀ (ν : Fin 2 → ℝ) (U : Set (Phase (2 + 2))) (S : Finset (Fin 2 → ℤ)) (P : Phase (2 + 2) → ℝ),
    IsOpen U → IsAngleSaturated U → U ⊆ poincareProdDom 2 → ContDiffOn ℝ ∞ P U →
    (∀ k ∈ S, ∀ w ∈ U, ∑ i, (k i : ℝ) * keplerFreq ν (fast w.2) i ≠ 0) →
    (∀ k ∈ S, -k ∈ S) → 0 ∉ S →
    (∀ w ∈ U, residual₁ (hProd 1 ν) P (chiStar S (keplerFreq ν) P) w = P w - projS S P w) ∧
    ∀ k ∈ S, ∀ w ∈ U,
      chartCoeff (residual₁ (hProd 1 ν) P (chiStar S (keplerFreq ν) P)) k w = 0

/-- (2d) **The order-2 part of `r₂` is the tail of `G₂`**: with `χ₁ = χ*(P)`,
`G₂ = {P - ½ Π_S P, χ₁}` and `χ₂ = χ*(G₂)`, `residual₂ = G₂ - Π_S G₂` on `U`, and its Fourier
coefficients on `S` vanish. -/
def Residual₂Tail : Prop :=
  ∀ (ν : Fin 2 → ℝ) (U : Set (Phase (2 + 2))) (S : Finset (Fin 2 → ℤ)) (P : Phase (2 + 2) → ℝ),
    IsOpen U → IsAngleSaturated U → U ⊆ poincareProdDom 2 → ContDiffOn ℝ ∞ P U →
    (∀ k ∈ S, ∀ w ∈ U, ∑ i, (k i : ℝ) * keplerFreq ν (fast w.2) i ≠ 0) →
    (∀ k ∈ S, -k ∈ S) → 0 ∉ S →
    let χ₁ := chiStar S (keplerFreq ν) P
    let G₂ := pb (fun y => P y - projS S P y / 2) χ₁
    let χ₂ := chiStar S (keplerFreq ν) G₂
    (∀ w ∈ U, residual₂ (hProd 1 ν) P χ₁ χ₂ w = G₂ w - projS S G₂ w) ∧
    ∀ k ∈ S, ∀ w ∈ U, chartCoeff (residual₂ (hProd 1 ν) P χ₁ χ₂) k w = 0

/-- (2e) **The small divisors of HD 11964, explicit**: `modesHD` is symmetric and omits `0`, and
on `openHD` every divisor satisfies `|k·ω(Λ)| ≥ ω_b(Λ) ≥ 1/(Λhi_b + 1/250)³` (the smallest,
`k = (0, ±1)`; for `k_c ≠ 0`, `|k_c ω_c| ≥ 41 ω_b > 20 ω_b + ω_b`). -/
def SmallDivisorsHD : Prop :=
  (∀ k ∈ modesHD, -k ∈ modesHD) ∧ (0 : Fin 2 → ℤ) ∉ modesHD ∧
    ∀ k ∈ modesHD, ∀ w ∈ openHD,
      1 / (lamHi 1 + 1 / 250) ^ 3 ≤ |∑ i, (k i : ℝ) * keplerFreq nu (fast w.2) i|

end HD11964.Cover

end
