## Target 1: the constant and the estimate

### The constant

`smallDivisorSup ω δ = ⨆ k, smallDivisorSupTerm ω δ k`. The term is `e^{-2πδ|k|₁}/(2π|k·ω|)` for `k ≠ 0` and
`0` at `k = 0`.
- **Why a `⨆`.** It composes best:
  - `le_ciSup` gives the pointwise bound used by the estimate;
  - `ciSup_le` gives every upper bound, through `smallDivisorSup_le_of_forall` (`0 ≤ B` and a bound on each
    `k ≠ 0`).
  - Certificates and comparisons only need that characterization.
- **Bounded above.** Boundedness comes from the Diophantine bound (`bddAbove_smallDivisorSupTerm`).
- **Without the Diophantine premise.** The `⨆` is still a real number (`0` if unbounded), but every theorem that
  uses it assumes `ω` Diophantine.

### The estimate (repository conventions)

Coefficient radius `s = 2πρ` for strip width `ρ` (in turns); `Fourier.weightedNorm s a = ∑' k, ‖a k‖ e^{s|k|₁}`.

```
summableWeighted_solve_sup (hω : Condition ω γ τ) (hγ : 0 < γ) (hτ : 0 ≤ τ) (hδ : 0 < δ)
    (ha : SummableWeighted s a) :
  SummableWeighted (s - 2πδ) (solve ω a) ∧
    weightedNorm (s - 2πδ) (solve ω a) ≤ smallDivisorSup ω δ * weightedNorm s a

summableWeighted_cohSolution_l1 (hω : IsDiophantine γ τ ω) hγ hτ hδ (hδρ : δ < ρ)
    (hs : SummableWeighted (2πρ) ĝ) :        -- ĝ = torusCoeff (g on ℝⁿ)
  SummableWeighted (2π(ρ - δ)) (torusCoeff (cohSolution ω g on ℝⁿ)) ∧
    weightedNorm (2π(ρ - δ)) (torusCoeff (cohSolution ω g on ℝⁿ)) ≤ Γ_∞(ω, δ) * weightedNorm (2πρ) ĝ
```

- **No holomorphy needed.** The coefficient estimate does not use holomorphy of `g`. The coefficients of
  `cohSolution ω g` are exactly `solve ω ĝ` (`torusCoeff_cohSolution_l1`, via `torusCoeff_fourierSum`).
- **The sup bound.** On `T_{ρ−δ}`, `‖cohSolution ω g θ‖ ≤ Γ_∞ A` whenever `‖ĝ‖_{ℓ¹,2πρ} ≤ A`
  (`norm_cohSolution_l1_le`, by `norm_fourierSum_le`).
- **The bridge** (`eq_fourierSum_of_summableWeighted`, `norm_le_weightedNorm_of_summableWeighted`). A
  holomorphic `1`-periodic `u` on `T_ρ` (`ρ > 0`) with `SummableWeighted (2πρ) û` equals `fourierSum û` on `T_ρ`
  and is bounded there by `‖û‖_{ℓ¹,2πρ}`.
  - **Proof.** `v = u − fourierSum û` has all coefficients `0`, so `eq_zero_of_torusCoeff_holomorphic` applies.
  - **Use.** ℓ¹ data satisfy the sup-norm premise `‖g‖ ≤ A` of every qualitative lemma of
    `KAM.Strip.Cohomological` / `…Operator` (`norm_le_of_l1{,_pi,_mat}`). Those lemmas are reused unchanged.
- **Vector data.** The ℓ¹ bound is componentwise, `‖ĝ_l‖ ≤ A` for every `l`, plus `0 ≤ A`. The sup bound is in
  the max norm.
- **Matrix data.** The ℓ¹ bound is in the operator sense: for every `‖v‖ ≤ 1` and every `i`, the coefficients of
  `x ↦ (g(x) v)_i` have ℓ¹ norm `≤ A`, plus `0 ≤ A`.
  - **Conclusions.** The same holds for `cohSolutionMat ω g` with `Γ_∞ A`, and the operator norm is
    `≤ Γ_∞ A` on `T_{ρ−δ}`.
  - **Route.** `(𝓡g)v = 𝓡(gv)` on `T_{ρ−δ}` by uniqueness (`mulVec_cohSolutionMat`, as in
    `norm_cohSolutionMat_sum_le`), and `isGreatest_norm_mulVec` gives the norm.
- **A-priori forms.** In `cohomological_apriori_l1` (scalar), ℓ¹ data on `∂_ω u` give `‖û‖_{ℓ¹,2π(ρ−δ)} ≤ Γ_∞ H`
  and `|u| ≤ Γ_∞ H`. `cohomological_apriori_operator_l1` (matrix) is the same in the operator sense.

### Node statements

`cohomological_l1` (scalar and `ℂ^p`) and `cohomological_operator_l1` (matrix, plus the a-priori form) keep the
standing premises of `KAM.cohomological` / `KAM.cohomological_operator` (`IsDiophantine γ τ ω`, `0 < γ`, `0 ≤ τ`,
`0 < δ`, `δ < ρ`).
- **Data premise.** The sup premise `∀ θ ∈ T_ρ, ‖g θ‖ ≤ A` is replaced by the ℓ¹ premise(s) above.
- **Bound clauses.** Each bound clause `‖sol θ‖ ≤ cohConst …·A` is replaced by three:
  - summability of the solution's coefficients at `2π(ρ−δ)`;
  - their ℓ¹ norm `≤ smallDivisorSup ω δ * A`;
  - the sup bound `≤ smallDivisorSup ω δ * A`.
- **Qualitative clauses.** Holomorphy, periodicity, zero average, the equation, realness and uniqueness are
  textually identical to the originals (see Checks).

## Target 2: comparisons

- **`smallDivisorSup_le_solveBound`.** `Γ_∞(ω, δ) ≤ solveBound γ τ (2πδ) = (2πγ)⁻¹ (τ/(2πeδ))^τ`.
  - This is the sup form of the Diophantine bound already in the repository, and the analogue of PlasmaLean's
    `1/(eγδ)` in our units.
  - In `c = Γ_∞ γ δ^τ` units it reads `c ≤ (2π)⁻¹(τ/(2πe))^τ`, which is `1/(4π²e) = 0.00932` at `τ = 1`.
  - It has no `δ^{-n}` loss and no lattice counting, against `cohConstR 2 1 = 0.316` for the sup-norm Rüssmann
    estimate.
- **The sup bound.**
  - `norm_le_weightedNorm_of_summableWeighted`: for holomorphic periodic `u`, `sup_{T_r}|u| ≤ ‖û‖_{ℓ¹,2πr}`.
  - For the solution, `norm_cohSolution_l1_le` (and the Pi/Mat versions) gives the sup-norm estimate with the
    same `Γ_∞`.
  - So the ℓ¹ route always also gives a sup-norm estimate.
- **`smallDivisorSup_le_sqrt_sum`.** `Γ_∞(ω, δ) ≤ (2π)⁻¹ S(ω, 2δ)^{1/2} ≤ (2π)⁻¹ S(ω, δ)^{1/2}`.
  - **Why it holds.** Each term of `Γ_∞` is `(2π)⁻¹` times the square root of a term of `S(ω, 2δ)`. `S` decreases
    in `δ` (`smallDivisorSum_anti`).
  - **The relation to SHARP-L2.** The SHARP-L2 constant is `(2π)⁻¹ 2^{n/2} S(ω, δ)^{1/2}`. So
    `Γ_∞ ≤ 2^{-n/2}·(SHARP-L2 constant)`, and the stronger form uses `S` at twice the loss.

## Target 3: certified upper bounds (`KAM/Strip/CohomologicalL1Cert.lean`)

**The tail.** For `|k|₁ ≥ N + 1`, the Diophantine bound and the monotonicity of `m^τ e^{-bm}` for `m ≥ τ/b`
(`rpow_mul_exp_le_tail`, from SHARP-L2's `rpow_mul_exp_le_geom`) bound each term by

`sdSupTail γ τ δ N = (N+1)^τ e^{-2πδ(N+1)} / (2πγ)`, provided `τ ≤ 2πδ(N + 1)`.

**General frequency.** `smallDivisorSup_le_box_tail (hω : IsDiophantine γ τ ω) hγ hτ (hN : τ ≤ 2πδ(N+1)) L hL E hE hB`
gives `Γ_∞(ω, δ) ≤ max B (sdSupTail γ τ δ N)`. The data on `modeBox n N` are:
- `0 < L k ≤ |k·ω|`;
- `e^{-2πδj} ≤ E j`;
- `E(|k|₁)/(2π L k) ≤ B`.

**Clock frequencies, fibered (`smallDivisorSup_snoc_le`).** For `ω = Fin.snoc ω' 1`, with:
- `τ ≤ 2πδ(N + 1)`;
- for each `k'` in `modeBox m N` (`0 < |k'|₁ ≤ N` in `ℤ^{n−1}`): an integer `p k'` with `|k'·ω' + p k'| ≤ 1/2`
  and `0 < L k' ≤ |k'·ω' + p k'|`;
- weights `E j ≥ e^{-2πδj}`;
- `E 1/(2π) ≤ B`;
- for each box entry, `E(|k'|₁ + |p k'|)/(2π L k') ≤ B` and `E(|k'|₁)/π ≤ B`;

the conclusion is `Γ_∞(Fin.snoc ω' 1, δ) ≤ max B (sdSupTail γ τ δ N)`.

The three kinds of mode are bounded as follows.
- **Fiber `k' = 0`.** `|k·ω| = |k_n| ≥ 1`, so the term is at most `e^{-b}/(2π)`.
- **Box fiber.** The nearest `k_n = p` keeps its full weight `e^{-b(|k'|₁+|p|)}`. Every other `k_n` has
  `|k'·ω' + k_n| ≥ 1/2`, so its term is at most `e^{-b|k'|₁}/π`.
- **`|k'|₁ > N`.** The tail.

This is the brief's `max(max_{0<|k′|≤N} e^{−2πδ|k′|}/(2πL), k′=0 fiber, tail)`. The nearest-mode weight is kept
in full, `e^{-b(|k'|₁+|p|)}` rather than `e^{-b|k'|₁}`, because `|p| ≈ |k'·ω'|` matters for `ω'` of size 1. One
entry per `k'`: `2N` entries for `n = 2`.

## Uncertainties

- **Different norms.** ℓ¹ data on `T_ρ` are more restrictive than sup data, so `c_∞` and `c_R` are not like for
  like. The headline is what an ℓ¹ scheme would gain, not a drop-in replacement for `cohomological_sum`.
- **Double precision.** The numbers are not Lean-certified; the Lean route is `smallDivisorSup_snoc_le` with
  rational data. The divisors are far above rounding: `|k'α + p| ≥ γ/(2|k'|) ≈ 10⁻⁷` at the largest `k'`, against
  `|k'|·10⁻¹⁶`.
- **PlasmaLean's conventions.** Its γ is taken as given (`ι/2`). The `|k|₁` norm in its exponent is assumed; the
  study (§8) states `‖u‖_{r−δ} ≤ ‖f‖_r/(eγδ)` without the norm. If it uses another norm, `Γ_∞` changes
  accordingly.

## Suspected errata and deviations

- **Errata.** None.
- **Deviation: `0 ≤ A` premises.** The vector and matrix ℓ¹ forms carry `0 ≤ A` (resp. `0 ≤ H`).
  - **Why.** For `p = 0` the componentwise ℓ¹ premise is vacuous, so it does not force `A ≥ 0`. The sup premise of
    the originals does, since the strip is nonempty.
  - **Status.** This is typing data, not a conclusion-shaped hypothesis.
- **Deviation: the matrix ℓ¹ norm.** It is taken in the operator sense: components of `g v`, `‖v‖ ≤ 1`. This
  matches "operator norm via u·v" in the brief and composes with `cohSolutionMat`. An entrywise row-sum bound
  (`∑_j ‖ĝ_ij‖_{ℓ¹} ≤ A`) implies it, given linearity of `torusCoeff` for continuous data. That convenience lemma
  is not proved here.
- **Deviation: the `S^{1/2}` comparison.** It is stated at twice the loss (`S(ω, 2δ)`), which is where it is true
  term by term. The weaker `S(ω, δ)` form follows and is included.

## What remains

- **An ℓ¹ Newton scheme.** To use `Γ_∞`, every other estimate would have to be in weighted ℓ¹ norms: products,
  Cauchy estimates, composition, and the a-posteriori layer. The frozen hypotheses are sup-norm (D12). This
  package supplies the cohomological node and its certificates only.
- **All δ at once.** As with SHARP-L2, `c_∞(δ)` is flat for both frequencies. A v2 interface can certify a few
  `δ_s` with `smallDivisorSup_snoc_le` (752–48898 entries for `δ₀ … δ₀/64`) and use `smallDivisorSup_le_solveBound`
  beyond, which loses at most the factor 18 (lunar) or 7.5 (PlasmaLean).
