## Conventions

- **Coordinates:** `x = (η, ξ)` with `q = η = x.1` and `p = ξ = x.2`. `KAM.hamiltonianVectorField` is
  `(∂H/∂p, −∂H/∂q)`, so `η̇ = ∂H/∂ξ` and `ξ̇ = −∂H/∂η`, as the dataset states (`{η_j, ξ_j} = 1`).
- **Complex variable:** `z_j = (ξ_j − iη_j)/√2` with `{z_j, z̄_j} = −i`. Every term has even degree, so
  `2^(−d/2)` is rational and the sum is real (SR-1: charge 0, real coefficients and `c_ab = c_ba` exactly).
- **Eccentricities:** `Γ_j = KAM.Planetary.oscillatorAction ξ η j = (ξ_j² + η_j²)/2 = |z_j|²` and
  `Γ_j = Λ*_j (1 − √(1 − e_j²))`.
