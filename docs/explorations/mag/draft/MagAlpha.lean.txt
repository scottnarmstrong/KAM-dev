/-- The rotation number `α = (43 + 18φ_g)/(74 + 31φ_g) = (7913 - √5)/13618`, `φ_g = (1 + √5)/2`
(continued fraction `[0; 1, 1, 2, 1, 1, 2, 3, 1̄]`, Valvo–Locatelli (12)); the barrier carries the
frequency `(α, 1)`. -/
def magAlpha : ℝ := (7913 - Real.sqrt 5) / 13618

end KAM.Magnetic
