## Main statements (exact)

**Composition, generic.**
```lean
theorem pevalAt_symPow (M : Mat3) (a : Mon) (w : Fin 3 → R) :
    pevalAt (symPow M a) w = mon a (M.apply w)
theorem bevalAt_composeLin (M : Mat3) (Cs : List (List ((Mon × Mon) × ℤ))) (w v : Fin 3 → R) :
    bevalAt (composeLin M Cs) w v = bevalAt Cs.flatten (M.apply w) (M.apply v)
theorem bevalAt_eq_dense (M : Mat3) (A : List Mon) (hA : A.Nodup) (L : List ((Mon × Mon) × ℤ))
    (hL : ∀ e ∈ L, e.1.1 ∈ A ∧ e.1.2 ∈ A) (S T H : List (List ℤ))
    (hSl : S.length = A.length) (hTl : T.length = A.length)
    (hSr : ∀ r ∈ S, r.length = A.length) (hTr : ∀ r ∈ T, r.length = A.length)
    (hS : ∀ i < A.length, symPow M (A.getD i default) = A.zip (S.getD i []))
    (hT : ∀ i < A.length, T.getD i [] = linComb A.length (cRowOf A L (A.getD i default)) S)
```

the composition is `H_d = S_dᵀ C_d S_d`.

## Approach
1. **Model → integers.**
   - `c · 10^33 ∈ ℤ` for every row (kernel).
   - The model is `Re(10^{-33} Σ_d C_d(z, z̄))` by degree (`IntModel`).
   - `sjsu18O2_eq_sum` compares summands pointwise: a whole-sum `rfl` makes the kernel evaluate the 7,941-term list.
2. **Rotation.** `z = V′w = M(w/N)` (`zOf_rotMap`). In each degree, verify `C_d(Mω, Mω̄) = H_d(ω, ω̄)` in the kernel:
   - `C<d>`: the literal integer rows equal the model's rows, converted (`listBEq`), and their keys lie in `A_d × A_d`.
   - `S<d>`: `S_i = symPow M (A_d i)`, one declaration per degree with one `listBEq` per row.
   - `T<d>`: `T_i = Σ_j C(A_i, A_j) S_j`, one declaration per row `i`. Row `i` of `C` is read off the literal rows
     (`cRowOf`).
   - `H<d>`: `H_k = Σ_i S_i[k] T_i`, one declaration per row `k`.
   - `bevalAt_eq_dense` assembles these into the polynomial identity.
   - Literals are signed integers in 320-bit hex limbs (`hz neg [limbs]`), one row per definition, data split into
     part files.
3. **Polar form.** `w_k = √I_k e^{iθ_k}` (`omegaOf_polar`, matching N2's `polar`). Then:
   - `Re` of each term is `c N^{−|b|−|b'|} Π √I^{b+b'} cos(Σ(b−b')θ)`;
   - charge zero (kernel: every key lies in `A_d × A_d` with `|A_d| = d`) turns the angle into `k·φ`;
   - `√I^n = (B + (I − B))^{n/2}` (`polarAmp_eq_binomProd`) makes the shift cancel. So `sjsu18O2_rotMap_polar` holds
     for every `B`.
4. **Grouping.** `T_n` groups the rows by `n = b + b'` (`list_sum_eq_sum_filter`, no kernel work):
   - `hTildeOf_taylor` splits each `binomProd` into N4's truncation plus remainder and swaps the sums;
   - `hRem_tube` sums N4's `binomProd_tube` bounds with weights `τ_n`, using the product rule for `∂_φ`.
5. **Rate.** Instantiates N2's `fderiv_comp_tubeChart_apply_hamiltonianVectorField` with `sjsuV_orth`,
   `sjsuB_add_two_pi`, `sjsuB_symm`, `sjsu18O2_chart` and `differentiableAt_hTildeOf`. At the chart image,
   `B + u = I > 0`.

## Uncertainties
- **Literal size.** The `Hw/` literal is 8 MB and 101k lines: `H_w` plus the intermediate `S` and `T` rows. Only
  `H` (as `sjsuHwAll`) is needed downstream. N7 should consume `sjsuHwAll` (exact) or round it into its own ledger.
- **Whitening.** The `Hw/` literals are not XOR-whitened. Their limbs are high-entropy 320-bit chunks, and the measured
  check times above are acceptable. If N7 sees the SR-6 hazard when importing them, whitening can be added in the
  generator.
- **Dependency on N6.** `SJSU/Ham/Center.lean` imports N6's `KAM.EffectiveStability.SJSU.Ecc.Data` (`sjsuEccModes`,
  `sjsuEccIbar`) and core `tubeCenter`, so the tube centre has one source. A rename there breaks `sjsuB`.
- **Unused generic code.** `composeLin`/`groupChunks` in `Compose.lean` are proved, but the SJSU instance no longer
  uses them; it uses the dense path.

## Deviations from the brief
- **Kernel instance.** It is a row-wise dense check (`S`, `T = C S`, `H = Sᵀ T`) rather than one `Sᵀ C S`
  declaration per degree (design signal 3). The literal `H_w` is still checked against the kernel computation. The
  independent cross-check is kam-g2's flint `compose` in `gen_hw.py` plus my generator's exact recomputation.
- **No separate `T_n` literal.** `T_n` is defined from the `H_w` rows by grouping (`Tn`), not as a separate literal. The
  grouping identity is a theorem, not a kernel check.
- **Real exponents.** `h̃` uses `binomProd (n/2)` with real exponents, to match N4; `√I^n = I^{n/2}` is proved.
- **Additions:** `sjsu18O2_rate` (end-to-end N2 instance), `HTildeBounds` (ℓ¹ bounds of `T_n`, differentiability) and
  `tubeCenter_add_two_pi`/`contDiff_tubeCenter`.
- **Frozen-text line length.** The draft-v2 texts of `sjsu18O2Part0..5` have one docstring line of 110 characters
  (`(applications/sjsu/data/sjsu18-o2.json, sha256 …, complex_form.terms, in file order). -/`). Lint flags it.
  I kept the approved text byte-identical, so it needs a `scripts/lint-width-allow.txt` entry or a text change by the
  owner.
