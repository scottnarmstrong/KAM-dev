## Approach
1. `spatial_safety_of_aligned` is the planar `planar_safety_of_prograde` line by line. Constants before `μ`, `z₀`: shared tube `U`
   (`exists_isSharedTube`); `spatial_stopped_drift` with `D₀ = 1` (`μ₁, c, T₀, w`); `spatialStrongBarrier_physical` and
   `spatial_osculating_barrier` for `(U, δ/2)`; budget radius `r₁` (spatial copy of the planar lemma); `r₂ = min r₁ r_g`;
   `dStar = min dS₁ dS₂`, `dPair = min dP₁ dP₂`; `AΛ = 1/2`; `Aa = (max C 0 + 1)(Σ ν⁻² + 1)`; `Aelem = A₂`, `Aosc` from OSC;
   `μ₀ = min(μ₁, μ₂, r₂², dS₁/(2Aosc), dP₁/(4Aosc))`. With `r = 1·√μ`: `SpatialLiftData` (the data of Lemma 14; `aligned` is the
   only orientation datum); `hstop` from `spatialChartLift_premises_nrr` and `spatial_stopped_drift` with `J = uIcc 0 t`, `t₁ = t`;
   then `spatialStrongFirstExit_of_stopped_drift`; conclusions from CONF, `spatialStrongBarrier_physical`,
   `spatial_osculating_barrier`, `spatialStrongAMD_sub_eq_sum`, `spatial_norm_axis_sub_le`.
2. Orientation in `lp2_…`: `L ≠ 0` from `angularMomentum3_ne_zero_of_strongAMD_lt` (AMD `≤ B − δ ≤ Λ_0 − δ`), then
   `exists_rotation_align_angularMomentum3` gives `R` (`RᵀR = 1`, `det R = 1`) with `L(R z₀)/|L(R z₀)| = e₃`; `R z₀` satisfies every
   premise (energies, axes, actions, chamber, AMD by invariance), is aligned, the aligned theorem applies, and
   `SpatialSafeSol.of_rotate` returns the solution `Rᵀ ∘ z'` for `z₀`; the Newton part is
   `isSpatialNewtonSolutionOn_of_isSpatialMovingSolutionOn` (L1) applied to the rotated-back solution.
