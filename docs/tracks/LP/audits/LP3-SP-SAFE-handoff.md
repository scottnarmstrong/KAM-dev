## Approach
Constants (before `μ`, `z₀`; depend on `(n, ν, A, δ)` only): shared tube from `exists_isSharedTube`; `spatial_stopped_drift_nek`
gives `B0 ≥ 1`, `μ1`; barrier (`spatialStrongBarrier_physical`) and osculating (`spatial_osculating_barrier`) constants for
`(U, δ/2)`; `Bb = B0^{b_n}`; `c = B0^{-a_n}`, `T₀ = 1` (`spatialNekHorizon = 1 * exp (c μ^{-a_n})` by `Real.mul_rpow`);
`AΛ = Bb/2` (radius `r = Bb μ^{b_n}`, drift `≤ r/2`); `Aa = (Bb/2)(2 max C 0 · Σ ν⁻² + 1)`; `dStar = min dS1 dS2`,
`dPair = min dP1 dP2`, `Aelem = A2`, `Aosc` from OSC; `μ₀ = min (min μ1 μ2) (min (dS1/(2Aosc)) (dP1/(4Aosc)))`.
The budget/radius conjuncts of the drift theorem (`r ≤ 4 r_g`, `n r + Ω ≤ δ/4`) supply `hball` and `hbudget`, so LP2's
`r2 = min r1 rg` and `μ ≤ r2²` are no longer needed. `SpatialLiftData` is built with `r = spatialNekRadius n B0 μ`;
`hstop` is `hdrift z₀ hz₀L hd` (literal, no conversion); then `spatialStrongFirstExit_of_stopped_drift`; conclusions as in
LP2. The rotation to `L = |L| e₃` is LP2's argument verbatim (`Main.lean`).
