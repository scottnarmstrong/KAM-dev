## Deviations (none strengthens a source hypothesis)

* **E1** (`k0`): stated in the inductive form at a fixed stage `ν`, with the increments of the earlier stages as
  hypotheses (they are what `iter-lemma` provides at those stages; the blueprint's "in the setting of
  Lemma `iter-lemma`" bundles them). Normal modes use W7's indexing: `j : ℕ`, label `normLab j = j + 3` (W5's `j + 2`
  for W5's `j ≥ 1`).
* **E2** (`convergence` (i), `exclusion`): the parameter sets are built from arbitrary frequency sequences; the
  statements hold for every such sequence, so they are slightly more general than the blueprint's (which builds them
  from the iteration outputs). Levels `a_ν` and thresholds `K_{ν-1}` are parameters (`Kp 0 = 0`).
* **E3** (`sequences`): `2^{-ν}` is written `1/2^ν`; `t`, `τ` are real (`t = stepExpT 24`), `σ^t` is `Real.rpow`; the
  stated `q_ν ≤ γ₀2^{-ν}` is proved through the stronger `q_ν ≤ γ₀4^{-ν}`.
* **E4** (Lipschitz seminorms, λ-norms): written as pointwise inequalities, e.g. `λ|f|^L ≤ c` as
  `λ ‖f ξ - f ζ‖ ≤ c ‖ξ - ζ‖` (W5 `bpW:w5:class` convention: "no supremum is taken as a value").
