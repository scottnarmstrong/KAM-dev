exported in two parts:

1. `homLieN_fin_expansion_gen` (`CompleteLieExpand.lean:169`). For any `F ∈ 𝒯_s` (no solve, no
   gate), `θ ∈ T_s` and `z, \bar z` supported in a finite `S`, `L_N F` (source-domain
   `homLieN_gen`, any carrier evidence `hC`) is the finite expression `bpW:w4:R` in which every
   coefficient function `g` is replaced by
   `homLieComp w λ g = (2π)⁻¹⟨ω, ∂_θ g⟩ − iλ g` (`CompleteLie.lean:58`). The `λ` values are `0, 0`
   for `a, b`; `Ω_j, −Ω_j` for `c^±_j`; `Ω_i+Ω_j, Ω_j−Ω_i, −(Ω_i+Ω_j)` for `P_ij, Q_ij, P'_ij`.
   `homRval_fin_true_gen` (`:61`) shows the same expression with `g` itself is the value of `F`.
2. `homCoeff_homLieComp` (`CompleteLie.lean:63`):
   `(homLieComp w λ g)^_k = i(⟨k,ω⟩ − λ) ĝ_k`. The per-component rules
   `homLieComp_coeff_a/b/cp/cm/P/Q/P'` (`CompleteLie.lean:131–185`) give it with the divisors
   `homDelta0`, `homDeltaPlus`, `homDeltaMinus`, `homDeltaP`, `homDeltaQ`, `homDeltaP'` and with the
   coefficients of the components (`homCoeff F.P k`, read through `homNormalEntry_gen`,
   `homTrueCoord`). `δ^Q_{0,jj} = 0` holds automatically.

expansion and the seven coefficient rules. `homLemma_lie_iii` (`:356`) is the `p_+ = p+1` form;
