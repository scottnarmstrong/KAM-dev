## Model (read before auditing)

* **Constants.** The W8 constants are W8-PREP's formulas evaluated at `w8Upstream m hm` (`γ = w6Gamma`,
  `γ₁ = w6Gamma1`, `c_F = w6CF`, `c^♮_F = w6CFn`); `w8T0W m hm = w8T0 m hm (w8Upstream m hm)`,
  `w8Eps0W m hm n = ε_{0,n} = κ_n^{4/3} γ₁ α̌_n`.
* **Per-shell input.** The blueprint runs `bpW:w6:prep-step` on shell `n` with the initial perturbation `P` of
  `bpW:w5:initial` (W5-AA, not in this base). Every per-shell result is stated for an arbitrary
  `H : W8ShellPrep m hm n P X` (`abbrev` for W6's `W6PrepHyp` at `Π_n, α_n, r_n, ε^♯_n`): this is exactly "the
  hypotheses of Lemma `bpW:w6:prep-step` for the data of `bpW:w8:shell-data` (iv)", i.e. the source premise of
  `sharp-prep` ("run Lemma prep-step with the data of shell-data (iv)"). `H` is built from W5's conclusion by the
  conditional helper `w8ShellPrep_of_initial`. The patched objects take a family
  `H : ∀ n, W8ShellPrep m hm n (Ps n) (Xs n)`.
* **Shell iteration.** `w8ShellSeqData m hm n = w6WaveSeq m hm α_n r_n ε^♯_n ε_{0,n}`, start `w8ShellStart H`,
  `Γ_n = w8ShellGamma H = H.wavePiStar ε_{0,n}` (`= w6PiStarIt …`), `ω^{(n)}_* = w8ShellOmega H` (`w6OmStar`),
  `ν^{(n)}_* = w8ShellNu H = (2π)⁻¹ • ω^{(n)}_*`, family `w8ShellFamily H = H.w6WaveFamily …`, excluded set
  `w8ShellExcl H`, `e^{(n)}_tor = w8ShellEtor m hm n = w6Etor …`, `ε^{(n)}_ω = w8ShellEpsOm m hm n`, torus in KAM
  coordinates `w8ShellTorusKam H = Φ^{(n)}_P ∘ Φ^{(n)}_*`.
* **`τ_E` and `K`.** W3's `BirkReal` and the frozen `WaveSpace` are the same type (weighted `E_{1,1}`, two copies
  of `ℓ²(ℕ+)`), so `τ_E = id`. `w8KOfBirk m hm Ψ θ = Γ^ℝ(Π Ψ(θ))` (`birkGammaR`, `Π = birkPi` = `𝒵⁻¹` on real
  points), totalized by `0` off `B^E_{r₁}`; at real points in the ball it equals `Π Γ(Ψ(θ))`
  (`w8KOfBirk_eq_gamma`, the blueprint's second expression). `K^{(n)}_ξ = w8Kshell A H ξ` takes the action–angle
