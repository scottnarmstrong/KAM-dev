## Blueprint / interface defects
1. **W7 inner shell vs W8 trimmed shell (blocks the verbatim use of W7 `shell_defect_le` in `nlw2-proof` Step `p-dens`).**
   W7's Lean `shellInner q t₀ k a = {I ∈ R_k | ∀ J ∉ R_k, a < dist I J}` is not `{dist(I, ℝ² ∖ R_k) > a}`: the infimum need
   not be attained (`ℝ² ∖ R_k` contains the open box `(0, t_{k+1})²`), e.g. points with `I₁ = t_{k+1} + a` and small `I₂`
   lie in `shellInner` but have `infDist = a`. So `shellInner` is not open and is not contained in W8's `Π_n`
   (Definition `bpW:w8:shells`, which must be open for `patch-local`/`patch-cont`). W7's `shell_defect_le` assumes
   `hinner : shellInner q t₀ k α_k ⊆ P_k`, which fails for `P_k = Π_n`. Suggested fix: weaken that hypothesis of
   `shell_defect_le` to the layer bound `volume (R_k ∖ P_k) ≤ ofReal (7 α_k t_k)`, which `volume_w8Rn_diff_w8Pi_le` provides
   for `Π_n` (W7's own proof only uses `hinner` to obtain that bound). Proved here: `Π_n ⊆ shellInner α_n`
   (`w8Pi_subset_shellInner`) and `shellInner b ⊆ Π_n` for `b > α_n` (`shellInner_subset_w8Pi_of_lt`).
2. The task list marked `const`, `patch`, `patch-local`, `patch-cont`, `nu-injective`, `injective` as W5/W6-free; they are
   not (see above).
3. Mathlib names in `bpW:w8:ext` all exist. `HasDerivAt.inner` gives `⟨f x, g'⟩ + ⟨f', g x⟩` (the blueprint writes the
   two terms in the other order; harmless). No wrong statement found in the W6-free labels.
