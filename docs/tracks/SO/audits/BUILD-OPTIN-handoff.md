## Points for the auditor

1. **DRAFT_SORRY anchors and the "roots only" lakefile.** The old glob was also what built the quarantined
   `nlw2` anchor and provider. The guard forbids any file, roots included, from importing them, so they are kept in
   the default build as generated `.one` globs. Check that this matches D51's "every core theorem is built".
2. **Lake library resolution.** Every `KAM.*` module, band data included, stays local to the library `KAM` (Lake's
   root-prefix rule), so it is built with `KAM`'s options whichever root reaches it. That is why the traces do not
   change, and why the application libraries only own their root files.
3. **Mapping completeness.** A new module that is not under `KAM.SpinOrbit.Data` and imports no application
   module defaults to core by design. Certificate data placed elsewhere would be built by `lake build` unless an
   application claims it.
4. **land-branch now stops** (exit 3) instead of building changed heavy data. Building them is now a deliberate
   `prebuild_heavy.py --lib`. This follows the brief; it changes the landing procedure.
