# N12 Lean design: averaging with stopped maximum error

Design evidence, 2026-10-28, branch `inp-design-n12`. Scope: every graph node whose statement or proof source is
`blueprint-N/parts/p12-averaging.tex`, including the two Part 0 frozen roots proved in Part 12.
No proof is supplied and no frozen declaration is changed. Appendix A is the exact signatures file;
all theorem bodies there are `sorry` under the design-only exception of DESIGN-COMMON.

## 1. Decisions

1. Use the frozen `HasAveragingFrequencyRank`, `averagingError`, `IsSolutionOn`, `actionBall`, and
   `KAM.realHamiltonian` literally. `avgH` is an exposed abbreviation by definition, not another Hamiltonian law.
2. Use `KAM.ODE.IsMaximalSolution` with its **EReal** endpoints. `avgMaximal` chooses a witness to that existing
   predicate; it introduces no second solution representation. Values outside the maximal domain are irrelevant.
3. Prove differentiable dependence as real finite-dimensional infrastructure (`ext_dep`), then chain it to
   the maximal flow. It is a theorem obligation, never an input premise to either averaging root.
4. Keep the complex corrector `w`, with a real phase domain and real Fréchet derivative. Prove the complex vector
   identity for the real inclusion of the action increment; the inclusion is isometric, so real drift estimates
   follow directly. Reality of `w` need not be established separately.
5. Envelopes and the stopped functional take values in `ℝ≥0∞`. Their finiteness on the action domain is proved;
   use no `toReal` without a finiteness lemma. The maximum error in the frozen result remains the **real** `sSup`.
6. Constants are chosen in order: `Ω₀,M₂`, rank transversality, slab `C₁`, Fourier `σ`, envelope constants,
   finite number of initial angle cells, then `A₁`. Set `ε₀=1`, `η₀=R/8`, most-data `A=A₁`, mean `A=13A₁`.
7. Internal results use `1 ≤ n`, as the blueprint permits. The provider exports keep frozen `2 ≤ n`.
   No other premise is dropped from the exported types. No frequency lower bound is added.
8. No imports from providers or draft anchors in implementation modules. Neither provider imports the other
   provider or its unsealed frozen anchor. They independently consume `Averaging/Mean` and `Averaging/Most`.

### Owner rules (verbatim; copy into each prover brief)

1. **Never use `set_option maxHeartbeats`** (or any heartbeat-budget override). A default-heartbeat elaboration

4. **No `axiom`, `admit`, `unsafe`, `opaque`; `sorry` only** as the manifest-bound body of a frozen statement in
   `KAM/Frozen/`. No recursion-depth or synthesis-heartbeat overrides either.
5. **Frozen files are read-only.** Never edit anything under `KAM/Frozen/` or `manifest/`. If a frozen
   declaration looks wrong, stop and report; never add a premise or substitute a helper.
6. **No conclusion-shaped hypotheses.** A theorem may assume only source premises, standing assumptions, typing
   data and explicit owner rulings. Conditional helpers get distinct names and never stand in for a source result.

| Corrector | `avgPsi`, `avgPsiD`, `avgU`, `avgW`, `avgResidual` | rational regularization, all modes including identically zero `k=0` term |

| Stopped estimate uniformity | `stopped` | M₂ and A₁ are chosen before `∀ f₁, IsAnalyticPerturbation R s 1 f₁ → ...` |
| Stopped maximum majorant | `avgStopped` | zero outside `avgStay` in the time integrand, so invalid flow values do not enter |
| Good data | `avgGood h f R ε η K` | subset of K, full-time existence and **strict** maximum `<η` |

Period is one, character `exp(2πi k·θ)`, geometric width `s`, decay `β_k=exp(-πs|k|₁)`.
There is no time or volume rescaling; all final measures are unnormalized phase volume.
Bounds use row sums of `avgM`, consistent with the max-norm operator estimate in the blueprint.
The `κ` regularization parameter and the final Markov budget `κ` live in different lemmas/scopes.
The denominator bounds involving `y⁻¹` require `y ≠ 0`; global rational bounds cover the resonant shell.
The stop set is open **relative to** nonnegative time and initial actions in `B(0,R/2)`.
All derivatives of solution curves at the ends of `[0,1/ε]` are two-sided `HasDerivAt`; the maximal
open interval supplies the endpoint neighborhoods. Do not weaken them to within-derivatives.

### Local dependence obligation, without a missing theorem hidden in a structure

Choose `δ` with `closedBall x₀ (2δ) ⊆ W`. On this compact ball obtain bounds `L` on F and `Λ` on DF.
Choose `a,r>0` with `r=δ/2`, `aL<δ/2`, `q=aΛ<1`; work with bounded continuous families on
`[-a,a]×closedBall x₀ r`, tracking their closed trapping constraint as a closed subset.
The complete-contraction node is Mathlib's contraction principle on this complete family space,
not the (generally incomplete) subtype of all C¹ functions with only the C⁰ norm.

Start `y₀(t,x)=x`, `Y₀(t,x)=id`, iterate `y_{m+1}=x+∫F(y_m)` and
`Y_{m+1}=id+∫DF(y_m)Y_m`. Prove parameter differentiation locally on the open initial ball by the
dominated derivative integral theorem; bounds `‖Y_m‖≤1/(1-q)` provide domination. Separately contract
`Z↦id+∫DF(y)Z` on continuous bounded linear-map families, producing continuous Y.
Uniform continuity of DF on the compact trap gives `d_m=sup‖DF(y_m)-DF(y)‖→0` and
`‖Y_{m+1}-Y‖≤q‖Y_m-Y‖+a*d_m/(1-q)`. Prove convergence from this recurrence; it is not
contraction of the pair `(y,Y)` under only C¹ assumptions. Apply the uniform derivative-limit theorem
on the open ball to conclude `D_x y=Y`, then FTC gives the variational equation. This pays all six
`ext-dep#...` nodes; no stronger C² or Lipschitz-DF premise is added.

For `flow`, concatenate local maps along a compact orbit arc, retaining a common neighborhood of the
initial point and a final extra time slab. Compose initial derivatives, derive the variational law
on each slab, and use uniqueness to identify with `avgFlow`. The inverse proof uses a shifted solution
of **F**, not of `−F`; maximality applied to the closed interval ensures endpoint room.
For determinant one, use symmetry of D²H to preserve `YᵀJY=J`, hence determinant ±1;
continuity on the connected maximal time interval and initial determinant 1 fix the sign.

### Corrector termwise differentiation gate (N12-06)

The `wreg` output must include, for every `z ∈ avgDomain n R` and every real phase direction `v`,
a `HasSum` of the real directional derivatives of the actual summands
`fun y => -KAM.character k (KAM.realInclusion n y.1) • avgU h f κ k y.2`, with sum
`fderiv ℝ (avgW h f κ) z v`. This equality holds on the entire source domain, before the `avgG`
guard used for the quantitative bounds. A residual contraction or derivative norm estimate alone
is insufficient. Set `v=(vθ,0)` and `v=(0,vI)` to recover the angle and action derivative series;
the derivative of the zero-mode summand vanishes.

For each point choose an open preconnected product neighborhood whose action closure lies in
`actionBall n R`. Use `coef` and the rational divisor bounds to dominate terms and their real
Fréchet derivatives locally by a constant times `(1+modeSize k)^3 * avgBeta s k`.
Instantiate `hasFDerivAt_tsum_of_isPreconnected` on that neighborhood, using the product and chain
rules for each summand; apply the resulting continuous linear maps to `v` to obtain the displayed
`HasSum`. This also justifies the expanded partial formulas in p12:122 and p12:128. Transport the
minus sign through the summable series to the definition of `avgW`. No bounds or regularity outside
the analytic domain are assumed. Downstream users of the former periodicity/bounds conjunct now
project the third conjunct of `wreg`; the first remains C¹ and the second is the new series identity.

### Transport and integrability gates

Do not merely estimate the volume of the unfolded image `Φ_t(D)` by a single angle box: angle drift
may traverse many period cells. Apply change of variables to D first, split the image into half-open
integer angle cells, translate each to the fundamental cell, and prove the translated pieces disjoint.
If two translated images overlap, flow translation and injectivity imply that their preimages differ
by an integer angle shift; two points in the same half-open initial cell then force the shift to zero.
Sum integrals over this disjoint union and use its inclusion in `[0,1)^n×G`. This is `transport`.

On K the killed integrand is jointly Borel because the flow is continuous on its open domain and the
stay set is relatively open there. Extend by zero **before** applying Tonelli; do not assert global
measurability of the chosen flow or of the envelopes outside their domains. The contribution from a
single endpoint `t=τ` is null, so the strict stopping indicator equals integration up to the closed
stopped time for this purpose. `pointwise` bounds every earlier time by the same nonnegative integral.
Finite angle cells meeting compact K are counted only after this per-cell estimate.

/-- Derived constant specification; it is NEVER a premise of a source theorem. -/
def AvgSlabBound (h : (Fin n → ℂ) → ℂ) (R C₁ : ℝ) : Prop :=
  1 ≤ C₁ ∧ ∀ k : Fin n → ℤ, k ≠ 0 → ∀ u : ℝ, 0 < u →
    volume {I ∈ avgG n R | |avgQ h k I| ≤ u} ≤
      ENNReal.ofReal (C₁ * u / euclid (fun j => (k j : ℝ)))
def avgLog (κ : ℝ) : ℝ := 1 + Real.log (1 / κ)

theorem shells_from_slab (d : AveragingData n R s h f) {C₁ Ω₀ κ : ℝ}
    (hC : AvgSlabBound h R C₁)
    (hΩ : ∀ I ∈ avgG n R, ‖KAM.frequencyMap h I‖ ≤ Ω₀)

      ENNReal.ofReal (3 * C₁ * (1 + Ω₀) * (1 + KAM.Fourier.modeSize k) * avgLog κ) ∧

    (∫⁻ I in avgG n R, ENNReal.ofReal (κ ^ 2 / (avgQ h k I ^ 2 + κ ^ 2))) ≤
      ENNReal.ofReal (5 * C₁ * κ / euclid (fun j => (k j : ℝ))) := sorry

/-- All envelope constants are computed, not postulated bound witnesses. -/
def avgSigma (s : ℝ) : ℝ :=
  ∑' k : Fin n → ℤ, if k = 0 then 0 else (1 + KAM.Fourier.modeSize k) ^ 3 * avgBeta s k
def avgCW (n : ℕ) (s C₁ Ω₀ : ℝ) : ℝ := 3 * C₁ * (1 + Ω₀) * avgSigma (n := n) s
def avgCB (n : ℕ) (s C₁ Ω₀ M₂ : ℝ) : ℝ :=
  avgSigma (n := n) s * C₁ * (6 * n * (1 + Ω₀) / s + 5 * Real.sqrt n * M₂)
def avgCR (n : ℕ) (s C₁ : ℝ) : ℝ := 10 * Real.pi * C₁ * avgSigma (n := n) s
def avgCPhi (n : ℕ) (s C₁ Ω₀ M₂ : ℝ) : ℝ :=
  4 / s * avgCB n s C₁ Ω₀ M₂ + 8 * Real.pi / s * avgCW n s C₁ Ω₀ + avgCR n s C₁

theorem envelopes_from_slab (d : AveragingData n R s h f) {C₁ Ω₀ M₂ : ℝ}
    (hC : AvgSlabBound h R C₁) (hΩ0 : 0 ≤ Ω₀) (hM0 : 0 ≤ M₂)
    (hΩ : ∀ I ∈ closedBall (0 : Fin n → ℝ) R, ‖KAM.frequencyMap h I‖ ≤ Ω₀)
    (hM : ∀ I ∈ closedBall (0 : Fin n → ℝ) R, ∀ i, ∑ j, |avgM h I i j| ≤ M₂) :
    (∀ κ : ℝ, 0 < κ → κ ≤ 1 →
      (∫⁻ I in avgG n R, avgWenv h s κ I) ≤ ENNReal.ofReal (avgCW n s C₁ Ω₀ * avgLog κ) ∧
      (∫⁻ I in avgG n R, avgW1env h s κ I) ≤
        ENNReal.ofReal (2 * Real.pi * avgCW n s C₁ Ω₀ * avgLog κ) ∧
      (∫⁻ I in avgG n R, avgBenv h s M₂ κ I) ≤ ENNReal.ofReal (avgCB n s C₁ Ω₀ M₂ / κ) ∧
      (∫⁻ I in avgG n R, avgRenv h s κ I) ≤ ENNReal.ofReal (avgCR n s C₁ * κ)) ∧
    ∀ ε : ℝ, 0 < ε → ε ≤ 1 →
      ENNReal.ofReal (2 * ε) * (∫⁻ I in avgG n R, avgWenv h s (Real.sqrt ε) I) ≤
        ENNReal.ofReal (4 * avgCW n s C₁ Ω₀ * Real.sqrt ε) ∧
      (∫⁻ I in avgG n R, avgPhiEnv h s M₂ ε (Real.sqrt ε) I) ≤
        ENNReal.ofReal (avgCPhi n s C₁ Ω₀ M₂ * Real.sqrt ε) := sorry
/-- Source-facing node with all quantitative constants derived from the fixed data. -/
theorem envelopes (d : AveragingData n R s h f) :
    ∃ C₁ Ω₀ M₂ : ℝ, AvgSlabBound h R C₁ ∧ 0 ≤ Ω₀ ∧ 0 ≤ M₂ ∧
      (∀ I ∈ closedBall (0 : Fin n → ℝ) R, ‖KAM.frequencyMap h I‖ ≤ Ω₀) ∧
      (∀ I ∈ closedBall (0 : Fin n → ℝ) R, ∀ i, ∑ j, |avgM h I i j| ≤ M₂) ∧
    (∀ κ : ℝ, 0 < κ → κ ≤ 1 →
      (∫⁻ I in avgG n R, avgWenv h s κ I) ≤ ENNReal.ofReal (avgCW n s C₁ Ω₀ * avgLog κ) ∧
      (∫⁻ I in avgG n R, avgW1env h s κ I) ≤
        ENNReal.ofReal (2 * Real.pi * avgCW n s C₁ Ω₀ * avgLog κ) ∧
      (∫⁻ I in avgG n R, avgBenv h s M₂ κ I) ≤ ENNReal.ofReal (avgCB n s C₁ Ω₀ M₂ / κ) ∧
      (∫⁻ I in avgG n R, avgRenv h s κ I) ≤ ENNReal.ofReal (avgCR n s C₁ * κ)) ∧
    ∀ ε : ℝ, 0 < ε → ε ≤ 1 →
      ENNReal.ofReal (2 * ε) * (∫⁻ I in avgG n R, avgWenv h s (Real.sqrt ε) I) ≤
        ENNReal.ofReal (4 * avgCW n s C₁ Ω₀ * Real.sqrt ε) ∧
      (∫⁻ I in avgG n R, avgPhiEnv h s M₂ ε (Real.sqrt ε) I) ≤
        ENNReal.ofReal (avgCPhi n s C₁ Ω₀ M₂ * Real.sqrt ε) := sorry

def avgCorrectionQ (h : (Fin n → ℂ) → ℂ) (f : AvgComplexPhase n → ℂ)
    (κ : ℝ) (z : AvgPhase n) : Fin n → ℂ :=
  fderiv ℝ (avgW h f κ) z (avgB f z, 0) + fderiv ℝ (avgW h f κ) z (0, avgA f z)

theorem identity (d : AveragingData n R s h f) {ε κ t : ℝ}
    (hε : 0 < ε) (hκ : 0 < κ) {x : AvgPhase n} (hx : x ∈ avgDomain n R)
    (ht : 0 ≤ t) (htp : (t : EReal) < avgTp h f R ε x) :
    KAM.realInclusion n ((avgFlow h f R ε t x).2 - x.2) =
      ε • (avgW h f κ (avgFlow h f R ε t x) - avgW h f κ x) -
      ε ^ 2 • (∫ u in (0 : ℝ)..t, avgCorrectionQ h f κ (avgFlow h f R ε u x)) +
      ε • (∫ u in (0 : ℝ)..t, avgResidual h f κ (avgFlow h f R ε u x)) := sorry

theorem pointwise (d : AveragingData n R s h f) {ε κ M₂ t : ℝ}
    (hε : 0 < ε) (hε1 : ε ≤ 1) (hκ : 0 < κ) (hκ1 : κ ≤ 1)
    (hM : ∀ I ∈ closedBall (0 : Fin n → ℝ) R, ∀ i, ∑ j, |avgM h I i j| ≤ M₂)
    {x : AvgPhase n} (hx : x.2 ∈ actionBall n (R / 2)) (ht : 0 ≤ t)
    (htp : (t : EReal) < avgTp h f R ε x)
    (htraj : ∀ u ∈ Icc 0 t, (avgFlow h f R ε u x).2 ∈ avgG n R) :
    ∀ u ∈ Icc 0 t, ENNReal.ofReal ‖(avgFlow h f R ε u x).2 - x.2‖ ≤
      ENNReal.ofReal (2 * ε) * avgWenv h s κ x.2 +
      ENNReal.ofReal ε * ∫⁻ v in Icc 0 t, avgPhiEnv h s M₂ ε κ (avgFlow h f R ε v x).2 := sorry

def avgCell (ell : Fin n → ℤ) : Set (AvgPhase n) :=
  {x | ∀ i, (ell i : ℝ) ≤ x.1 i ∧ x.1 i < (ell i : ℝ) + 1}

theorem transport (d : AveragingData n R s h f) (ε : ℝ) {t : ℝ} (ht : 0 ≤ t)

def avgStopped (h : (Fin n → ℂ) → ℂ) (f : AvgComplexPhase n → ℂ)
    (R s M₂ ε : ℝ) (x : AvgPhase n) : ℝ≥0∞ :=
  ENNReal.ofReal (2 * ε) * avgWenv h s (Real.sqrt ε) x.2 + ENNReal.ofReal ε *
    ∫⁻ t in Icc 0 (1 / ε), (avgStay h f R ε).indicator
      (fun p => avgPhiEnv h s M₂ ε (Real.sqrt ε) (avgFlow h f R ε p.1 p.2).2) (t, x)

def avgGood (h : (Fin n → ℂ) → ℂ) (f : AvgComplexPhase n → ℂ)
    (R ε η : ℝ) (K : Set (AvgPhase n)) : Set (AvgPhase n) :=
  {x ∈ K | x ∈ avgOmega h f R ε (1 / ε) ∧
    sSup ((fun t => ‖(avgFlow h f R ε t x).2 - x.2‖) '' Icc 0 (1 / ε)) < η}

/-- Uniform witness chosen before epsilon, eta, or any supplied solution family. -/
theorem stopped (d : AveragingData n R s h f) (K : Set (AvgPhase n))
    (hK : IsCompact K) (hKI : ∀ x ∈ K, x.2 ∈ actionBall n (R / 2)) :
    ∃ M₂ A₁ : ℝ, 0 ≤ M₂ ∧ 0 < A₁ ∧
      (∀ I ∈ closedBall (0 : Fin n → ℝ) R, ∀ i, ∑ j, |avgM h I i j| ≤ M₂) ∧
      ∀ f₁ : AvgComplexPhase n → ℂ, IsAnalyticPerturbation R s 1 f₁ →
      ∀ ε : ℝ, 0 < ε → ε ≤ 1 →
        Measurable (K.indicator (avgStopped h f₁ R s M₂ ε)) ∧
        (∫⁻ x in K, avgStopped h f₁ R s M₂ ε x) ≤ ENNReal.ofReal (A₁ * Real.sqrt ε) ∧
        ∀ x ∈ K, ∀ t : ℝ, 0 ≤ t → t ≤ 1 / ε → (t : EReal) ≤ avgTau h f₁ R ε x →
          ∀ u ∈ Icc 0 t, ENNReal.ofReal ‖(avgFlow h f₁ R ε u x).2 - x.2‖ ≤
            avgStopped h f₁ R s M₂ ε x := sorry
